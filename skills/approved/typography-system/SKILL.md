## Local authority
Authority: **typographic-system methodology**. Define roles before selecting fonts; evaluate candidates for legibility, language coverage, weights/styles, platform delivery and licensing; then define scale, line height, measure, responsive values and anti-patterns.

It may NOT:
- select type solely for historical resemblance or mood;
- add a third family without an explicit documented exception;
- ignore licensing or Spanish/English glyph requirements;
- overwrite a custom DIVINIVID wordmark construction with body/display font rules.

## DIVINIVID use
Use during Foundations after Signature hypotheses have been tested. Historical inscription/editorial references inform character but do not excuse poor screen readability or generic luxury-serif defaults.

## Output contract
Role map; candidate rationale; final type families; tokenized scale; mobile values; measure limits; licensing/fallback notes; do/don't rules.
