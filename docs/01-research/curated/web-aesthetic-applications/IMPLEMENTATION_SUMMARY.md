# Web / Aesthetic Applications Summary

Key implementation principles retained from the research:

1. Separate **Aesthetic**, **Functional** and **System** spines.
2. Build maturity progresses: `S0 Visual -> S1 Interactive -> S2 Mock Data -> S3 Backend Wired -> S4 AI/MCP`.
3. A visually finished interface must not be represented as functionally/systemically complete.
4. Apply licensing/provenance gates to fonts, imagery, icons and generated/reference assets.
5. AI/MCP integrations require explicit security, permissions, secrets, trust boundaries, output handling and observability design.
6. Commission agents using acceptance criteria, failure conditions, scope boundaries and capability matrices rather than open-ended prompts.
