# Key Research Inputs

## BOLD
Use as contrarian strategic evidence against a generic AI/automation agency and as input on productized/diagnostic-led models. Do not treat its recommendation as pre-decided truth.

## Spark final closure
Use for competitor patterns, offers/pricing signals, ICP/VoC hypotheses, positioning, funnels, proof, operations, AI services, naming, visual territories, web references and implementation ideas. Treat unsupported precision as hypothesis.

## Web / Aesthetic Applications
Use for the Aesthetic / Functional / System separation, staged implementation maturity, licensing/provenance gates, security constraints and commissioning discipline.

## Human visual calibration
Use Visual Taste Profile / Anti-Profile / Seed Synthesis as brand-preference calibration only; never as evidence of commercial market attractiveness.
