## 2. The critical path

```text
U-01…U-05 answered  →  target list  →  outreach instruments  →  D3 ACCESS
   →  D4 RESONANCE  →  D5 MONETISATION  →  first delivery  →  D6 DELIVERY
   →  first case study  →  D8 REPEATABILITY  →  D9 RECURRING  →  scale
```

**Everything on this line blocks everything after it. Nothing else does.**

Notably **not** on the critical path: Brand V1 · the production website · the asset factory · the
technical labs · any further strategic planning. All are valuable; none of them gates the first
customer. Confusing a parallel track for the critical path is the specific failure this roadmap is
structured to prevent (`RT-01`).
