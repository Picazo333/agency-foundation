# Convergence Gates

## Gate 1 — Brand/Business Fit
Requires Brand Direction V0 + Agency Master Plan.

## Gate 2 — Strategy + Brand Freeze
Requires reviewed strategy, unresolved validation flags, and an adjusted Brand V1 direction.

## Gate 3 — Implementation Readiness
Requires Brand V1, web architecture, content/proof inputs, asset plan and technical specs.

## Gate 4 — Launch Readiness
Requires production web, critical integrations, QA, analytics, sales/ops readiness and explicit open-risk acceptance.
