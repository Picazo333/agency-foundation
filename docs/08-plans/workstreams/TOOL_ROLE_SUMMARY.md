# Tool Role Summary

- **ChatGPT:** synthesis, naming, brand direction, meta-review.
- **Claude/CoWork:** agency master planning, strategy reconciliation, operations/validation planning.
- **Gemini:** asset-factory architecture, later brand-consistent asset production.
- **Codex:** implementation, refactors, tests, scripts, infrastructure, repo-aware coding.
- **Antigravity:** multi-agent technical experiments, motion/interaction labs and prototypes.
- **Jules:** narrowly scoped GitHub issues returning PRs.
- **Cursor:** implementation/debugging when local/IDE context is advantageous.

Tools are replaceable. Repository state is persistent.
