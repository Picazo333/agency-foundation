# Branch Conventions

Use short-lived branches such as:
- `brand/naming-exploration`
- `brand/visual-direction-v0`
- `plan/claude-master-agency`
- `asset/gemini-foundry-architecture`
- `tech/agent-foundation`
- `feat/<feature>`
- `fix/<issue>`

Avoid long-lived `develop` unless project complexity later justifies it.
