## Source-quality hierarchy for Phase 3
Prefer, in order:
1. collecting institution / artist foundation / archive / national library;
2. open-access museum catalogue;
3. authoritative film institution/publisher for copyrighted cinema reference;
4. scholarly project with stable manuscript/source metadata;
5. secondary editorial source only when primary visual/context data is unavailable.

Avoid Pinterest, repost aggregators, AI recreations, unsourced scans and moodboard blogs as provenance roots.
