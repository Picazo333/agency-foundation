# DIVINIVID Archive V1 — Volume Map

The archive is delivered as eight independent byte-preserving ZIP volumes plus VOL00 index because the single ~589 MiB ZIP exceeds the reliable attachment size of the current environment.

Extract all eight content volumes into the same parent folder. They share the root `DIVINIVID_VISUAL_UNIVERSE_ARCHIVE_V1/`.

- VOL01 — Core Identity / Visual Universe
- VOL02 — Anatomy / Specimens / Transformations
- VOL03 — Bestiary / Entities
- VOL04 — Environments / Impossible Geometry + Digital / Web / Mobile
- VOL05 — Motion Master Language
- VOL06 — Editorial / Typography / Information + Communication / Physical
- VOL07 — Asset Factory Bridge + known failures + duplicates + source evidence + legacy HTML
- VOL08 — Experiments / auto-named unverified / potential aesthetic drift

Full per-file metadata lives in the CSV/JSON manifest embedded in every volume and in VOL00.
