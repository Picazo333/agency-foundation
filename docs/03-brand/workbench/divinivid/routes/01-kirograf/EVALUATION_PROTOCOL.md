# KIROGRAF Evaluation Protocol

## Decision vocabulary
Every material round ends with one of:
- `PASS` — hypothesis/layer is strong enough to become an input to the next phase;
- `MUTATE` — underlying hypothesis survives but named corrections are required before promotion;
- `KILL` — hypothesis is retired; useful failure evidence is recorded if durable.

## Eight transversal gates

### 1. Intent
Does the artifact answer the active phase brief rather than merely resemble the source universe?

### 2. Duality
Are the relevant poles genuinely co-present? Does the composition/design establish a relationship rather than allowing one pole to erase the other?

### 3. Reference
Can the operator name the extracted source principles? Is the work translating mechanisms instead of imitating whole styles?

### 4. Distinctiveness
Could the artifact plausibly be a template for another creative/AI/luxury/gothic agency? If yes, mutate or kill.

### 5. Systemness
Can the artifact be explained as repeatable rules? One spectacular image with no reusable logic does not constitute identity progress.

### 6. Application
Does it survive outside a hero image or art-board context? Phase-appropriate application proof is required.

### 7. Contamination
Did an unapproved generated artifact, stale route board or Anti-Canon default leak into the result?

### 8. Craft
Does the actual execution deserve to survive, independently of a strong concept description?

## Critical-fail conditions
Any of the following blocks `PASS`:
- KIROGRAF used as public Brand instead of DIVINIVID;
- direct Anti-Canon cliché is the primary identity mechanism;
- asset/reference rights state is incompatible with the proposed use and not explicitly constrained to reference-only;
- output cannot state what hypothesis was tested;
- output relies on an unapproved generated board as its source;
- tool/model self-approves its output;
- phase Definition of Done is materially incomplete.

## Review order
1. producing operator self-check;
2. specialist method check where applicable;
3. Taste / anti-generic challenge where applicable;
4. Impeccable/refinement only after concept survives;
5. independent red-team or alternate reviewer for major convergence gates;
6. human creative-owner decision.

## 5-Up validity check
A 5-Up is invalid when the five candidates share the same underlying mechanism and differ only through:
- font substitution;
- crop;
- palette swap;
- decorative source image;
- mockup format;
- minor symbol geometry.

A valid 5-Up changes the causal design mechanism or structural relationship being tested.
