# DIVINIVID — Visual Base v1

## Human decision

The owner explicitly confirmed that DIVINIVID has now reached the intended visual aesthetic.

The latest approved mutation/application sequence is no longer being treated as competing aesthetic routes. It is now understood as a **single visual identity with multiple application systems**.

This checkpoint therefore locks the current direction as:

**DIVINIVID VISUAL BASE v1 — APPROVED**

This is the canonical visual base for subsequent system development.

## Core thesis

DIVINIVID is a contemporary codex for observing impossible phenomena.

Its identity combines:
- near-absolute living darkness;
- crimson as living/transmuting matter;
- ivory as knowledge / breathing space;
- restrained aged gold as measure, calibration and sacred emphasis;
- surgical editorial discipline;
- controlled oneirism;
- anatomical logic by analogy rather than literal anatomy;
- transformation across scales;
- liturgical structure without generic occult branding;
- scientific observation as a presentation method rather than a biotech aesthetic.

### Short formula

`LIVING DARKNESS + LIVING CRIMSON + SURGICAL CODEX + CONTROLLED ONEIRISM + ANATOMY BY ANALOGY + TRANSFORMATION ACROSS SCALES`

## Core aesthetic is now FROZEN

The following are no longer open-route questions:

### Living Darkness
Darkness behaves as:
- absorbent field;
- substrate;
- containment;
- concealment;
- threshold;
- material with depth.

It is not merely a black background.

### Living Crimson
Crimson behaves as:
- pulse;
- membrane;
- marrow;
- circulation;
- transformation;
- emergent matter;
- bridge between microscopic and cosmic scale.

It must not collapse into literal blood/gore.

### Surgical Codex
Presentation is:
- precise;
- modular;
- annotated;
- measured;
- calm;
- editorial;
- almost scientific.

The contrast is intentional:
**deeply imaginative matter presented with almost surgical clarity.**

### Controlled Oneirism
Surrealism enters through:
- impossible continuity;
- scale shifts;
- state changes;
- spatial dislocation;
- structural metamorphosis;
- micro ↔ macro analogies.

It does not enter through random collage or generic surreal spectacle.

### Anatomy by Analogy
Anatomy is recovered as structural behavior:
- geology ↔ bone;
- canyon / fracture ↔ medullary channel;
- crimson river ↔ marrow;
- vessel ↔ specimen / organ-like container;
- membrane ↔ eclipse;
- cell-like form ↔ moon;
- cavity ↔ interior world.

Literal dissection, exposed anatomy and gore remain outside the canon.

# Ten-board canonical universe

The current visual base is represented by ten approved boards, each with a distinct role.

## 01 — Master Canon
Defines:
- core thesis;
- anchor imagery;
- non-hero applications;
- key motifs;
- canonical palette;
- tone;
- KEEP / EVOLVE / NEVER;
- the master visual territory.

## 02 — Typography & Editorial Voice
Defines:
- monumental wordmark behavior;
- display / text / supporting roles;
- numerals and chapter marks;
- annotation language;
- editorial hierarchy;
- typographic restraint.

Specific font families remain provisional until formal foundations.

## 03 — Color, Material, Texture & Light
Defines:
- absorbent black;
- ivory parchment;
- living crimson;
- blood-maroon depth tone;
- mineral grey;
- restrained aged gold;
- porous, filament, membrane and crystalline material families;
- reveal / absorb / transmute lighting behavior.

## 04 — Image Universe
Defines:
- impossible structures;
- living matter;
- symbolic landscapes;
- specimens;
- fragments of human presence;
- celestial analogies;
- macro/micro textures;
- explicit DO / DON'T image rules.

## 05 — Surgical Codex Grammar
Defines:
- page architecture;
- modular grid;
- panel families;
- visual DNA;
- typography roles;
- annotation syntax;
- diagram language;
- layout states;
- application logic.

This is the principal bridge between aesthetic and product/system presentation.

## 06 — Medullary Landscapes
Defines the first major structural application:
- geology as anatomy by analogy;
- fracture / canyon / cavity;
- marrow-like crimson flows;
- cross-sections;
- topography as living structure;
- scale continuity.

## 07 — Specimen Vessels
Defines containment as an application system:
- sphere;
- capsule;
- plate;
- chamber;
- dual vessel;
- membrane;
- specimen comparison;
- observation modules;
- containment geometry.

The vessel is a means of observing impossible phenomena, not a biotech aesthetic.

## 08 — Transformative Morphologies
Defines transformation across scales and states:
- cell-like form → membrane → disintegration → reconfiguration → eclipse → red moon;
- marrow → landscape;
- specimen → symbol;
- micro → meso → macro;
- matter changing scale while retaining identity.

This board is a primary source for future motion language.

## 09 — Bestiary Entity System
Defines a **derived brand-entity / mascot system**, not the master Brand aesthetic.

Purpose:
- narrative entities;
- mascots;
- section or campaign beings;
- cataloged archetypes;
- symbolic guides / antagonists / states.

### Bestiary-specific palette exception
Within this subsystem only, the palette may expand into:
- ultramar / lapis-derived blue;
- aged gold / manuscript gold;
- ivory;
- black;
- restrained crimson traces.

This exception must not leak into the primary DIVINIVID palette.

### Illustration rule
Entities should be strongly informed by:
- medieval illuminated-manuscript illustration;
- bestiary plates;
- liturgical framing;
- heraldic / marginal illustration logic.

Avoid:
- fantasy RPG character art;
- modern concept-art rendering;
- generic monsters;
- neon;
- mascot-cartoon simplification.

## 10 — Application Systems
Defines first system-level translation across:
- website;
- research/report;
- presentation decks;
- editorial/print;
- brand elements;
- app interfaces;
- iconography/UI;
- environmental applications;
- merchandise / objects;
- optional narrative extensions.

These remain directional system proofs, not final production assets.

# Global anti-canon

Do not:
- reopen free-form aesthetic exploration unless explicitly requested;
- replace the primary black/crimson/ivory/gold palette with the Bestiary ultramar palette;
- use cyan/neon;
- drift into biotech/pharma UI;
- use gore or literal dissection;
- use fantasy-RPG rendering;
- use generic occult symbols as decoration;
- over-ornament;
- reduce the identity to one red planet, one specimen vessel, or one landscape;
- confuse derived systems with the master aesthetic.
