# DIVINIVID Composition Grammar V1

## 0. Purpose

Formalize approved composition evidence into a reproducible system.

This document does not introduce a new visual route, grid aesthetic, palette, signature, image family or motion behavior.

A capable designer should be able to produce a recognizably DIVINIVID composition from these rules without copying M1-B, B1, a hero board or any source reference.

## 1. Authority and invariants

Frozen inputs:
- Core: Living Darkness, ambiguous living matter, macro/micro duality, editorial authority + dream logic;
- B1: printed-evidence behavior, active negative space, registration logic, controlled incompleteness;
- P2: Minimal / No-Icons; signs only where semantically real;
- P3: H-B Editorial / Systemic as default hero behavior;
- P4: D2 Controlled / Expressive Mosaic as default density;
- R1: S-BE bilateral global architecture + glyph-class logic;
- R2: Newsreader + IBM Plex Sans and locked production color mapping.

Composition may arrange these variables. It may not redefine them.

## 2. Global composition law

Every major DIVINIVID composition should resolve three perceptual functions:

1. **Primary event** — the dominant reading or material event.
2. **Subordinate evidence system** — typography, caption, specimen relation, sectional evidence, supporting matter or real annotation that explains/anchors the event.
3. **Recovery zone** — a materially quieter region that restores hierarchy, legibility and tension.

This is a functional triad, not a mandatory three-column layout.

### Default perceptual sequence
`ORIENT -> WITHHOLD -> REVEAL / DISTURB -> REFRAME -> RECONCILE`

Not every surface needs every beat, but the final state must read as an intentional system rather than unresolved collage.

## 3. Spatial principles

### 3.1 Void is active
Negative space may:
- define a body through absence;
- separate evidentiary layers;
- create a pause before dense matter;
- carry concealment/revelation;
- establish a central or off-axis threshold.

Void must never be treated merely as empty black padding.

### 3.2 Order precedes anomaly
The viewer must first perceive enough hierarchy to recognize the violation.

Do not begin with undifferentiated chaos.

### 3.3 Localized density
Concentrate complexity.
Protect calm.

Dense and quiet regions should coexist on the same system unless the application constraint explicitly calls for an extreme D1 or D4 mode.

### 3.4 Asymmetry is default; bilateral logic is conditional
Use asymmetry for energy, editorial movement and heterogeneous structures.

Use strong bilateral/central-axis structure only when justified by:
- DIVINIVID signature mechanics;
- anatomy;
- mirror/reconciliation logic;
- ceremonial emphasis;
- a real semantic comparison.

Do not turn bilateral logic into a universal centered template.

### 3.5 Mosaic != card grid
Fragments can vary strongly in:
- scale;
- crop;
- aspect;
- material family;
- density;
- relation to the void.

Equal cards, repeated shells and bento-template rhythm are anti-system behavior.

## 4. Density scale

- **D1 Restrained** — low visual load; function, clinical/B2B sensitivity, long reading, low-quality reproduction.
- **D2 Controlled / Expressive Mosaic** — default.
- **D3 Expressive** — stronger collisions, larger image events, campaign/editorial escalation.
- **D4 Ceremonial** — rare, signature/high-intensity presentation; not default product behavior.

Intensity escalation must increase **meaningful event density**, not decorative noise.

## 5. Composition modes

The current execution plan operationalizes the older Master Plan modes into five production-facing modes:

- Contemplative;
- Editorial / Systemic;
- Anatomical / Topographic;
- Information-Dense;
- Ceremonial.

Legacy correspondence:
- `Anatomical Plate` -> Anatomical / Topographic;
- `Illuminated Page` -> editorial/ceremonial page logic without literal manuscript pastiche;
- `Dramatic Revelation` -> Ceremonial;
- `Contemplative` and `Information-Dense` retain their functional roles.

The legacy labels remain historical intent, not permission to revive literal historical styling.

---

## 5.1 CONTEMPLATIVE

### Hierarchy
One dominant event, minimal secondary evidence, generous recovery field.

### Void / matter
Void dominates.
Matter appears as a singular or sparse presence rather than a mosaic.

### Module rhythm
Few modules; large intervals; discontinuous pacing is allowed.

### Type / image relation
Typography can be monumental but should not compete with the primary image/matter event.
Long body copy is acceptable if the visual event recedes.

### Density
D1 by default; low D2 maximum.

### Crimson amplitude
Rare and localized.
Crimson should behave as event, not atmosphere.

### Instrumentation / signs
Near-zero.
Only captions, labels or structural marks with real semantic function.

### Typical use
- manifesto opening;
- title / chapter surface;
- high-trust editorial pause;
- low-imagery application;
- clinical/B2B-sensitive context when mystery must remain restrained.

### Failure threshold
MUTATE if:
- quiet becomes generic luxury minimalism;
- darkness is merely empty black;
- the composition depends on gold/serif prestige codes;
- lack of matter removes DIVINIVID ambiguity.

---

## 5.2 EDITORIAL / SYSTEMIC

### Hierarchy
Primary event + explicit information architecture + subordinate evidence.

### Void / matter
Balanced.
Void organizes reading; matter interrupts and deepens the editorial system.

### Module rhythm
Asymmetrical sections, varied widths/scales, controlled repeated alignment.

### Type / image relation
Newsreader establishes editorial authority; IBM Plex Sans carries navigation, evidence and operations.
Image and type are co-primary depending on content.

### Density
D2 default.

### Crimson amplitude
Low-to-moderate.
Use as semantic signal, sectional event or material rupture.

### Instrumentation / signs
Sparse but available when content-specific and true.
No decorative scientific metadata.

### Typical use
- default hero/system surface;
- case-study opening;
- service explanation;
- research/editorial feature;
- brand/system overview.

### Failure threshold
MUTATE if:
- it reads as conventional editorial luxury;
- the system becomes a clean SaaS grid;
- every block has equal weight;
- morphology becomes wallpaper;
- annotation exists only to look technical.

---

## 5.3 ANATOMICAL / TOPOGRAPHIC

### Hierarchy
A morphological field or sectional body is primary; evidence/caption logic explains without literalizing it.

### Void / matter
Matter and void define each other.
Cropping should preserve ambiguity across anatomy / geography / geology / architecture.

### Module rhythm
Plate-like or sectional groupings are allowed, but with heterogeneous scale and open transitions rather than museum taxonomy.

### Type / image relation
Image/matter usually leads.
Typography names, frames or interprets without collapsing ambiguity.

### Density
D2 default; D1 for clinical contexts; D3 for editorial escalation.

### Crimson amplitude
Moderate when the concept is rupture, vascular/tectonic transition or transformation.
Do not paint all anatomy red.

### Instrumentation / signs
Only real sectional labels, captions, numbering or evidence relationships.
P2 remains controlling.

### Typical use
- material/process explanation;
- case-study evidence;
- transformation narratives;
- research/editorial;
- controlled anatomical/cosmic ambiguity.

### Failure threshold
MUTATE or KILL if:
- it becomes medical illustration as branding;
- anatomy is decorative texture;
- it reads as specimen-board cosplay;
- exact literal body identification removes macro/micro ambiguity;
- gore becomes the first read.

---

## 5.4 INFORMATION-DENSE

### Hierarchy
Information is primary.
Matter supports hierarchy, evidence and pacing rather than dominating it.

### Void / matter
Recovery zones must remain explicit even under high information load.

### Module rhythm
Higher module count is allowed, but modules must form a hierarchy rather than a flat matrix.

### Type / image relation
IBM Plex Sans handles operational density.
Newsreader is reserved for headings, chapter logic and high-value editorial emphasis.

### Density
D2-to-D3 in information quantity, but visual spectacle should remain D1-to-D2.

### Crimson amplitude
Functional and sparse.
Use `crimson/ui` on dark or `crimson/matter` as a bounded accent on light only within R2 rules.

### Instrumentation / signs
Most permissive mode for real data, labels and structured evidence.
Still no fake coordinates, arbitrary scales or decorative crosshairs.

### Typical use
- reports;
- research;
- process/system explanation;
- case-study evidence;
- dense service architecture;
- operational/clinical/B2B surfaces.

### Failure threshold
MUTATE if:
- grid logic becomes the visual identity;
- visual matter compromises scanability;
- each datum receives equal emphasis;
- hierarchy depends on color alone;
- motion interferes with reading order.

---

## 5.5 CEREMONIAL

### Hierarchy
One unmistakable focal event with subordinate inscription/evidence and a controlled high-intensity field.

### Void / matter
Large-scale darkness/void may withhold the event; revelation can be staged around the focal mass.

### Module rhythm
Fewer, larger, more dramatic modules.
Asymmetry or bilateral/axial structure may be used deliberately.

### Type / image relation
Monumental Newsreader / S-BE signature behavior can carry equal weight with a major visual event.

### Density
D3 default; D4 allowed rarely.

### Crimson amplitude
Moderate-to-high by DIVINIVID standards, but still semantic and localized.
Crimson must not become a generic full-frame brand wash.

### Instrumentation / signs
Minimal.
Ceremonial intensity comes from hierarchy, matter, void and revelation—not added glyphs.

### Typical use
- manifesto;
- campaign;
- signature presentation;
- major launch moment;
- high-intensity editorial opener.

### Failure threshold
KILL or MUTATE if:
- it reads as occult branding;
- it becomes black/gold dark luxury;
- intensity is carried by generic Gothic motifs;
- spectacle overwhelms legibility;
- Bestiary B0 entities are introduced by default.

## 6. Cross-mode invariants

Every mode must preserve:
- recognizable DIVINIVID typography/foundations;
- at least one active tension rather than pure prettiness;
- controlled macro/micro relation;
- real hierarchy;
- meaningful negative space;
- anti-canon compliance;
- the ability to function without decorative icons.

## 7. Transition rule between modes

Modes are contextual states, not separate identities.

A surface may transition between modes only by changing bounded variables such as:
- density;
- ratio of void to matter;
- amount of annotation;
- size/count of modules;
- image dominance;
- crimson amplitude.

Do not change:
- signature architecture;
- type families;
- color primitives;
- core material semantics;
- anti-canon boundaries.

## 8. Reproduction test

A composition is reproducible if another capable designer can answer:
1. which mode is active;
2. what the primary event is;
3. what the subordinate evidence system is;
4. where the recovery zone is;
5. what density tier is active;
6. why any crimson/sign/instrument is present;
7. what failure threshold would invalidate the surface.

If those answers require seeing the original anchor, the grammar has failed.
