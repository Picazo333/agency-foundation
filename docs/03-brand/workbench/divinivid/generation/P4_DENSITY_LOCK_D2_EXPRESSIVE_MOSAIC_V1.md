## Default density principle
The default DIVINIVID expression is neither sparse/minimal nor ceremonial saturation.

It uses:
- controlled structural order;
- expressive variation;
- multiple visual planes;
- a puzzle/mosaic relationship between fragments;
- heterogeneous structures that still resolve into one composition.

## Core tension
The approved D2 refinement should feel like:
`ORDER <-> CREATIVITY`

Order is carried by:
- editorial alignment;
- framing;
- module boundaries;
- hierarchy;
- typographic discipline;
- repeated spatial rules.

Creativity is carried by:
- variable structural specimens;
- collisions of biological/geological/cosmic readings;
- irregular fragment sizes;
- asymmetry;
- material variation;
- selective crimson events.

Neither side should fully dominate.

## Structural variety rule
Do not repeat one morphology across every tile.

A D2 composition may combine, for example:
- porous marrow/bone-like structure;
- layered geological strata;
- fibrous or branching matter;
- cracked plate/sediment surfaces;
- ambiguous planetary mass;
- membrane/void structures;
- topographic contours;
- red vascular/tectonic transitions.

The structures must remain ambiguous and native to the same universe.

## D1–D4 roles
- `D1_RESTRAINED`: clinical, documents, functional UI, lower-intensity contexts.
- `D2_CONTROLLED`: **default system density**.
- `D3_EXPRESSIVE`: campaign/editorial escalation.
- `D4_CEREMONIAL`: rare signature, manifesto, bestiary/high-intensity use.

D1/D3/D4 remain valid application modes; they are not the default.

## Preserve
- P1 typography authority;
- P2 Minimal / No-Icons;
- P3 H-B Editorial/Systemic hero behavior;
- M1-B ambiguous morphology;
- B1 printed-evidence / negative-space logic.

## Avoid
- equal-size corporate card grids;
- repeating the same texture in every cell;
- fake scientific annotation;
- decorative complexity without hierarchy;
- expression that destroys navigability;
- order so rigid that the system becomes generic modernism.
