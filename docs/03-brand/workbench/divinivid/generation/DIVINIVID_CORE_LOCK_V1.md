# DIVINIVID Core Lock V1

## Decision
The human owner approved the current DIVINIVID Core as the stable visual DNA from which future translations, challengers and implementation systems must derive.

This lock does **not** make every depicted motif or generated symbol canonical. It locks the visual grammar and behavioral invariants below.

Library:

- library_file_id: `libfile_278d9c1a6e0481919c7966d0b0c88060`

## Core invariants
1. Living Darkness is an active habitat, not a neutral black background.
2. Matter behaves as living evidence: membrane, fracture, sediment, mineral, bone, smoke, tissue, void and transformation may overlap.
3. Forms should often support ambiguous reading across biological, cosmic, architectural, geographic or symbolic scales.
4. The system preserves macro/micro duality: monumental phenomena coexist with archival micro-instrumentation.
5. Editorial order and dream logic must coexist. Image without system is incomplete; system without mystery is incomplete.
6. Living Crimson is event/matter/transformation, not decoration.
7. Aged gold is measurement, hierarchy, annotation and ritual precision, not generic luxury.
8. Ultramar is residual and rare; it must never become the dominant atmospheric color.
9. Typography carries solemn editorial authority and remains subordinate to the universe rather than converting the artifact into a corporate brand board.
10. Entities are apparitions/intelligences/specimens, not conventional fantasy characters.
11. Elegance, depth and ambiguity are non-negotiable.
12. The system must avoid generic gothic, occult-core, dark-luxury and generic fantasy shortcuts.

## Ambiguous-form rule
Primary forms should preferably admit more than one credible interpretation.

Examples of acceptable behavior:
- celestial body / living tissue;
- geology / marrow;
- landscape / membrane;
- architecture / anatomy;
- specimen / organism / relic;
- void / body / threshold.

Literal depiction is not required and is often undesirable.

## Entity rule
Allowed entity logic may include:
- liminal harlequin-like intelligences;
- abstract infernal manifestations;
- biblically inspired multi-ocular / multi-structural angelic forms;
- hybrid bestiary presences between organism, relic, constellation, architecture and specimen.

The following are not automatically canonical:
- any single generated creature;
- any unapproved icon family;
- conventional angel/demon/fantasy character design.

## Color discipline
Guidance, not a rigid percentage formula:
- Living Darkness: dominant field;
- ivory/bone: revealed evidence and reading surface;
- Living Crimson: semantic event/matter;
- aged gold: structure/instrumentation;
- ultramar: residual trace only.

## Iconography status
Iconography remains a controlled sub-system and is **not** fully locked by this document.

Permitted by default:
- restrained measurement axes;
- observation targets;
- indexing marks;
- specimen boundaries;
- archival coordinates;
- registration devices.

Not approved by default:
- decorative occult glyphs;
- random alchemical signs;
- fantasy sigils;
- new symbol families inferred from one generated board.

## Anti-drift
Hard visual failures include:
- generic premium black/gold branding;
- blue/cyan science-fiction UI;
- dark-academia parchment takeover;
- literal medical illustration as identity shorthand;
- conventional fantasy/monster concept art;
- gothic architecture/statues/skulls used as automatic mood shortcuts;
- equal-card corporate brand-board composition replacing the universe.

## Reopen rule
This lock may be reopened only by explicit human decision with a documented rationale.

Future mutations must be described as:
- translation;
- challenger;
- branch;
- application mode;
- or amendment.

They must not silently rewrite the Core.
