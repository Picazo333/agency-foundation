## Repair mechanics

### S-A — Palindromic Axis
Amplified the central `N` as a visible hinge while preserving quieter bilateral wings.

Learning target:
Can the palindrome itself become the strongest signature architecture without becoming a novelty mirror trick?

### S-B — Bilateral Body
Amplified position-based paired mass around the central spine:
- outer mass;
- inner compression;
- center emphasis;
- mirrored size rhythm.

Learning target:
Can body-like bilateral order remain severe and editorial without becoming literal anatomy?

### S-C — Sacred Inscription
Reduced morphological intervention and increased inscriptional restraint through:
- smaller wordmark scale;
- wider spacing;
- more deliberate monumental rhythm.

Learning target:
Can authority and proportion alone create enough specificity?

### S-D — Mirrored Cut
Retained unchanged as the control because it was already visibly differentiated.

Learning target:
Can repeatable negative-space cuts carry the identity without becoming stencil/tech styling?

### S-E — Custom Letterform Logic
Rebuilt around a repeatable glyph-class rule:
- every D follows the same proportion logic;
- every I follows the same proportion logic;
- every V follows the same proportion logic;
- N follows the same native construction family.

This is glyph-class based, not position-based like S-B.

Learning target:
Can the four-glyph alphabet `D/I/V/N` create a scalable native display signature?
