## Core rule
DIVINIVID does **not** use a decorative icon system by default.

Identity is carried primarily by:
- matter;
- morphology;
- typography;
- spatial composition;
- negative space;
- color semantics;
- editorial hierarchy.

Signage is subordinate and functional.

## Allowed sign behavior
Use only when it carries a real, content-specific function:
- section markers;
- numbering;
- true data labels;
- actual process/state indicators;
- real callout anchors;
- semantic brackets/dividers;
- content-specific diagram marks.

## Explicit prohibition: fake instrumentation
The following are prohibited when they do not correspond to real information:
- generic coordinates;
- arbitrary latitude/longitude;
- decorative scales;
- meaningless crosshairs;
- random scientific tick marks;
- fake plate numbers;
- invented specimen metadata;
- lines that point to nothing meaningful;
- faux-technical annotations used only to make the design appear scientific.

This behavior is considered AI slop because it simulates meaning instead of carrying meaning.

## Morphology rule
Morphological concepts such as:
- cavity;
- fracture;
- membrane;
- transition;
- pressure;
- rupture;
- erosion;

should normally remain embodied in the visual matter itself.

Do not automatically convert them into a pictogram system.

## Minimal-sign principle
Default state:
`NO ICONS UNLESS A REAL FUNCTION REQUIRES ONE`.

When a sign is needed:
1. derive it from the specific content/function;
2. keep it minimal;
3. avoid decorative symbolism;
4. ensure it still makes sense with the artwork removed;
5. do not imply measurement/data that does not exist.
