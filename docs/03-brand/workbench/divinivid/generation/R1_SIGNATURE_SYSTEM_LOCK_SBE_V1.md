# R1 Signature System Lock — S-BE Bilateral Body + Glyph-Class Logic

## Decision

The human creative owner approved **S-BE — Bilateral Body + Glyph-Class Logic** as the DIVINIVID R1 Signature System architecture.

This closes R1.

## Selected mechanism

The selected signature is a layered system with explicit ownership of variables:

- **S-B Bilateral Body** controls the **global wordmark architecture**:
  - bilateral staging;
  - mirrored positional mass;
  - central spine;
  - whole-word rhythm and balance.

- **S-E Custom Letterform Logic** controls the **internal glyph-class behavior**:
  - every D follows one repeatable class logic;
  - every I follows one repeatable class logic;
  - every V follows one repeatable class logic;
  - N follows the same native construction family;
  - the logic is class-based, not position-based.

The combination is therefore systemic rather than decorative.

## Rejected final alternatives

- **S-B pure** remains evidence but is not the selected final architecture.
- **S-E pure** remains evidence but is not the selected final architecture.
- **S-A' Palindromic Axis** remains useful conceptual evidence only.
- **S-C Sacred Inscription** remains killed.
- **S-D Mirrored Cut** remains killed.

No rejected candidate may silently re-enter the Signature System.

## Palindrome role

The palindrome is a structural property of `DIVINIVID`, not a decorative effect.

The final architecture may express bilateral balance and central-spine logic, but must not turn the central `N` into an oversized gimmick or invent mirror effects merely to advertise the palindrome.

## Reduced-mark policy

P2 Minimal / No-Icons remains authoritative.

R1 does **not** authorize a decorative monogram or separate symbol by default.

Primary reduced behavior remains wordmark-first.

A future auxiliary mark may exist only if a real functional need emerges and it can be derived from the locked signature architecture without creating a new icon route.

## Color / imagery independence

The signature must remain viable:
- black on ivory;
- ivory on black;
- one-color;
- without imagery;
- without texture;
- without crimson;
- without ornamental framing.

The identity must not rely on the larger visual universe to remain recognizable.

## Production typography caveat

The Figma evidence uses **Newsreader as a construction substrate only**.

This lock approves the **signature architecture**, not Newsreader as the production typeface.

R2 Foundations is responsible for:
- font licensing;
- ES/EN support;
- weights/styles;
- web and print delivery;
- variable-font behavior where applicable;
- accessibility/readability;
- technically viable shortlist;
- final deterministic Figma comparison.

Any production font chosen in R2 must preserve the S-BE architecture rather than silently redesigning it.
