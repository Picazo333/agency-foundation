# DIVINIVID Temporal Identity V1

## 0. Purpose

Map the approved P5 motion grammar to the original Temporal Identity behavior set and close conceptual gaps without inventing a second motion language.

This document formalizes roles.
It deliberately defers exact production durations, easing constants, library choice and implementation performance to P6 / technical validation.

## 1. Temporal thesis

DIVINIVID motion should make meaning feel:
- withheld;
- discovered;
- briefly destabilized;
- reconciled.

Primary choreography:

`OBSCURE -> MISREGISTER -> REVEAL -> RESOLVE`

Motion modifies relationships.
It must not redesign the static identity.

## 2. Core behaviors

---

## 2.1 REVEAL

### Mapping
Original `REVEAL` -> **M-C Negative Revelation**.

### Mechanism
Meaning appears because a layer withdraws, erodes, masks away, opens or exposes active negative space.

### Use
- hero introduction;
- section opening;
- high-value heading/image reveal;
- image/matter disclosure;
- transition from mystery to evidence.

### Composition compatibility
Strongest in:
- Contemplative;
- Editorial/Systemic;
- Anatomical/Topographic;
- Ceremonial.

Use more conservatively in Information-Dense.

### Image compatibility
Strong with:
- Membrane/Void;
- Celestial Mass;
- Topographic/Coastal;
- Porous Marrow;
- negative-shape treatment.

### Failure
Generic wipe/fade, scanner reveal, glow effect, concealment so long that content access is impaired.

### Reduced-motion equivalent
Present the resolved hierarchy immediately, optionally using a simple opacity/visibility state change without spatial spectacle.

---

## 2.2 DISSECTION

### Mapping
Original `DISSECTION` -> **bounded segmented Registration**.

No new motion family is required.

### Mechanism
A coherent image/system separates into meaningful plates, sections or evidence layers, then may realign.

The separated parts must correspond to a real composition/image structure.

### Use
- sectional explanation;
- process decomposition;
- before/after structural evidence;
- layered material analysis;
- mosaic assembly/disassembly.

### Composition compatibility
Best in:
- Anatomical/Topographic;
- Editorial/Systemic;
- Information-Dense.

### Image compatibility
Strong with:
- Geological Strata;
- Porous Marrow;
- Topographic/Coastal;
- Printed Evidence overlay.

### Failure
Gore/cutting metaphor, arbitrary slice animation, exploded-view gimmick with no informational role.

### Reduced-motion equivalent
Show the sections already separated or use a static stepped state sequence.

---

## 2.3 ILLUMINATION

### Mapping
Original `ILLUMINATION` -> **semantic disclosure inside Negative Revelation**.

No separate glow motion language is authorized.

### Mechanism
Contrast/light reveals a semantic target or changes hierarchy.

Illumination can be temporal through:
- localized exposure;
- movement from darkness into readable evidence;
- a restrained pigment/event becoming visible;
- a field resolving from withheld to legible.

### Use
- emphasis;
- evidence discovery;
- focal transition;
- ceremonial reveal;
- controlled body/material disclosure.

### Composition compatibility
All modes, with intensity scaled down in Information-Dense.

### Image compatibility
Especially:
- Celestial Mass;
- Membrane/Void;
- Sculptural/Figure Presence;
- Porous Marrow.

### Failure
Bloom, neon edge, cinematic light sweep with no target, purple/cyan tech glow.

### Reduced-motion equivalent
Resolved high-contrast state present immediately.

---

## 2.4 MIRROR

### Mapping
Original `MIRROR` -> **bilateral/relational Registration** bounded by S-BE and conceptual equivalence.

### Mechanism
Two opposed or related states share axis, rhythm or staged alignment and move toward/away from a common relation.

Mirror is conceptual equivalence, not a visual-effect preset.

### Use
- body/cosmos comparison;
- before/after conceptual equivalence;
- signature/palindrome moments;
- reconciliation of paired states;
- ceremonial bilateral emphasis.

### Composition compatibility
Use only where bilateral structure is justified.
Particularly compatible with Ceremonial and selected Editorial/Systemic surfaces.

### Image compatibility
Pair related families only when a credible structural relation exists.

### Failure
Generic symmetry, mirrored-video effect, kaleidoscope, central-axis gimmick.

### Reduced-motion equivalent
Display the paired resolved states simultaneously.

---

## 2.5 ABERRATION -> RECONCILIATION

### Mapping
Original behavior -> **M-B Registration: MISREGISTER -> RESOLVE**.

### Mechanism
Selected layers temporarily shift out of registration, then return to a stable coherent relation.

### Use
- section transitions;
- state changes;
- layered mosaic transitions;
- conceptual disturbance before clarity;
- transformation between evidence states.

### Composition compatibility
Editorial/Systemic, Anatomical/Topographic and Ceremonial by default.
Use minimally in Information-Dense.

### Image compatibility
Printed Evidence strongly supports this behavior.
Any family may participate if treated as a layer rather than liquified material.

### Failure
Glitch, RGB split, chromatic aberration, perpetual instability, motion that reads as loading/error.

### Reduced-motion equivalent
Skip misregistration; move directly between stable states or use a discrete state change.

## 3. Secondary behaviors

### 3.1 M-A Breathing Matter
Optional ambient behavior only.

Use when:
- a living field benefits from almost imperceptible temporal presence;
- motion is not required for comprehension.

Do not:
- scale/pulse like a generic app animation;
- deform matter visibly;
- compete with reading.

Reduced motion:
- remove entirely.

### 3.2 M-D Instrument Response
Optional functional microinteraction.

Use for:
- hover;
- navigation;
- disclosure state;
- focus/selection response;
- real content-specific controls.

Must obey:
- P2 Minimal / No-Icons;
- R2 color contrast;
- semantic-state accessibility.

Reduced motion:
- static state change with equivalent non-motion cue.

## 4. Temporal character

Motion should be:
- deliberate;
- restrained;
- tactile;
- editorial;
- slightly uncanny;
- materially grounded.

Preferred temporal shape:
- tension may build through a short misregistration/disclosure;
- resolution should feel more stable than disturbance;
- no oscillation after the semantic state is resolved.

Exact numeric durations/easings are intentionally deferred.

## 5. Mode-to-motion budget

### Contemplative
- primary: sparse Negative Revelation;
- optional: near-imperceptible Breathing Matter;
- avoid repeated transitions.

### Editorial / Systemic
- primary: Negative Revelation + Registration;
- secondary: Instrument Response.

### Anatomical / Topographic
- primary: Dissection mapping + Registration + Negative Revelation;
- avoid visceral cutting effects.

### Information-Dense
- primary: functional Instrument Response and minimal reveal;
- structural motion must never reorder comprehension unpredictably.

### Ceremonial
- may use full `OBSCURE -> MISREGISTER -> REVEAL -> RESOLVE` choreography;
- spectacle ceiling still applies.

## 6. Accessibility / reduced motion

Every temporal behavior requires:
- same content availability;
- same semantic state;
- same hierarchy;
- same interaction outcome

when motion is reduced or removed.

Motion may reinforce meaning.
It may not be required to understand meaning.

Focus, hover, selected, expanded and error states need non-motion cues.

## 7. Production boundary

R5 does not lock:
- milliseconds;
- easing curves;
- CSS/WAAPI/GSAP/Motion library;
- GPU/shader strategy;
- breakpoint behavior;
- performance budgets.

Those are implementation questions for P6 / later technical feasibility.

A motion prototype is justified only when a specific continuous/timing question cannot be answered from this grammar.
