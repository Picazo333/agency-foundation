# DIVINIVID — Anti-Canon

## Purpose
The Anti-Canon records directions that should **not** be rediscovered by agents, generators, designers or future reviews simply because they are common, attractive or adjacent to the approved references.

A prohibited direction can only be reopened by explicit human decision with a stated reason.

---

# 1. Explicit aesthetic rejections

- cyan;
- neon;
- cyberpunk;
- AI-purple / “AI future” gradients;
- gaming/Razer-like visual language;
- glassmorphism;
- generic SaaS bento identity;
- startup-tech particle/glow systems;
- trendy brutalist agency template;
- pseudo-luxury black/gold;
- fragrance/fashion-brand minimalism used as a substitute for identity;
- tarot shop / occult-brand shorthand;
- Pinterest dark academia;
- fantasy-RPG medievalism;
- generic Gothic cosplay;
- modern medical/clinical branding;
- botanical-vintage-pretty as a central direction;
- random grunge/noise as “historical texture”;
- stock imagery or generic AI-slop aesthetics.

---

# 2. Explicit reference rejections / limits

## The Passion of Joan of Arc
Not a core taste reference. Do not infer that all canonical black-and-white historical cinema is on-brand because Macario, Seventh Seal and Caligari are strong references.

## Wim Crouwel / modernist grid spectacle
May inform invisible information structure if useful, but modernist/grid aesthetics must not dominate the personality.

## Generic Gothic architectural systems
Gothic architecture alone is not KIROGRAF or DIVINIVID. Architecture must carry silence, scale, ritual, materiality or narrative function.

## Decorative belladonna/botanical vintage
Nature/material references remain possible; ornamental vintage botany is not a preferred identity shortcut.

# 3. Process-derived anti-patterns from failed generations

## A. `SERIF + STATUE + BLACK + STAR`
Treat this combination as a hard warning. It is a repeated generative default that falsely reads as “serious sacred premium.” It is not a valid DIVINIVID solution by itself.

## B. KIROGRAF becomes the public Brand
Hard fail. `DIVINIVID` is the Brand; KIROGRAF is internal route metadata.

## C. Black/ivory/burgundy reduction
Hard warning. The source canon includes actual medieval polychromy, particularly ultramarine, carmine/vermilion and aged gold. Restricting everything to a dark luxury palette erases source intelligence.

## D. Anatomy as decoration
Hard fail when anatomy has no semantic role. Anatomical material must express knowledge, body, section, structure, transformation or revelation.

## E. Medieval = beige parchment
Hard fail. Illuminated manuscripts are frequently saturated and materially rich. Beige-only medievalism is a modern cliché.

## F. Grotesque = gore
Hard fail. Approved grotesque is symbolic anomaly, hybridity, deformation, marginalia and beautiful→strange→unsettling transition.

## G. Contemporary = brutalist/Swiss/trendy web design
Hard warning. Contemporary means current behavior, production quality, responsive logic, accessibility and information handling — not a prescribed fashion.

## H. One generator solves everything
Hard fail. Do not ask one generative image to resolve logo, typography, layout, UI, assets and brand system simultaneously.

## I. Five copies disguised as divergence
Hard fail under the 5-Up Rule. If variants differ only in crop, palette, font choice or decorative imagery while sharing the same mechanism, the divergence round is invalid.

## J. Self-referential generation loop
Hard fail. Unapproved generated outputs may not become positive references for later generation.

---

# 4. Negative quality signals

Reject or mutate work that:
- could plausibly belong to any “creative AI agency”;
- relies on darkness to simulate depth;
- uses gold to simulate sacredness/luxury;
- uses religious symbols without conceptual necessity;
- uses demons/angels as content rather than system;
- has no visual hierarchy under ornament;
- has no usable state without hero imagery;
- only looks convincing inside a polished mockup;
- cannot explain why a source principle was translated the way it was;
- cannot survive monochrome or small-scale tests where relevant;
- becomes illegible/inaccessible in real UI;
- depends on historical source material so strongly that it cannot build contemporary digital surfaces.

# 6. 2026-09-21 drift incident — explicit hard warnings

The A16–A20 generation attempt exposed a repeated generator drift toward a separate "sacred luxury editorial" aesthetic.

Treat the following as **hard warnings unless the exact contract + Canon require the element semantically**:

- generic skull;
- decorative skeleton;
- classical / Greco-Roman bust;
- generic premium statue;
- decorative halo;
- angelic sculpture as sacred shorthand;
- Gothic cathedral or arch used only for atmosphere;
- moon/eclipse used only as dark ambience;
- generic cloaked figure used only for solemnity;
- anatomical bust/cutaway used only to signal "body";
- ivory/white editorial takeover caused by a technical/audit topic.

## Why this matters
A technically themed board (accessibility, factory readiness, constraints, governance, etc.) is still a DIVINIVID board. The topic may change the **content**, but it must not silently create a new visual direction.

## Positive-reference isolation
Anti-Canon imagery must not be mixed into the positive generation reference set. Use Anti-Canon primarily as textual exclusions or in isolated QA comparison tasks.

Unapproved recent generated boards are never style references.
