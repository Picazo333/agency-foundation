# DIVINIVID — Phase 5 Iteration Contract

## Purpose
Define how original visual identity discovery will proceed after Phase 4 passes.

Phase 5 is **not** a one-shot identity-generation exercise. It is a controlled discovery loop in which original DIVINIVID directions are generated, compared, mutated and progressively proven as systems.

The first images are hypotheses. They are not expected to be final Brand assets.

---

# 1. Core rule

`GENERATE → REVIEW → NAME THE SIGNAL → MUTATE ONE VARIABLE → RETEST → PROVE AS SYSTEM → CONVERGE`

Do not iterate by vague instruction such as `make it better`.

Every mutation must identify:
- what is preserved;
- what changes;
- why it changes;
- what question the new artifact is meant to answer.

---

# 2. Phase-5 route set

The first 5-Up tests five distinct mechanism hypotheses.

## 01 — VESALIAN ABERRATION
**Core:** anatomical/scientific rigor containing one controlled impossibility.

Primary operations: `CONTAIN + INVADE`.

Learning target: determine whether classical anatomical order can become a proprietary Brand structure rather than historical pastiche.

## 02 — DARK REVELATION
**Core:** concealment, mortality, threshold and semantic illumination.

Primary operations: `REVEAL + RECONCILE`.

Learning target: determine whether DIVINIVID can be recognized through darkness/revelation behavior before explicit grotesque imagery appears.

## 03 — ONEIRIC ANATOMY
**Core:** anatomy subjected to controlled surreal displacement.

Primary operations: `DISLOCATE + TRANSFORM + REVEAL`.

Learning target: determine the usable surrealism ceiling and whether dream logic can become repeatable Brand grammar.

## 04 — BESTIARY OF SYSTEMS
**Core:** creature/anomaly treated through classification, annotation and editorial rigor.

Primary operations: `CONTAIN + MIRROR + INVADE`.

Learning target: determine whether grotesque/bestiary logic can become a serious contemporary information system.

## 05 — SACRED CORPOREAL
**Core:** ritual seriousness, unsettling body presence and transcendence.

Primary operations: `MIRROR + RECONCILE + REVEAL`.

Learning target: determine whether sacred/corporeal tension can remain elegant without collapsing into Gothic, occult or luxury cliché.

# 3. Iteration ladder

## Round A — Five-route divergence
Create exactly **one strong hypothesis artifact per route**.

Purpose: compare mechanisms, not polish.

Each artifact must state:
- route;
- operation stack;
- X1–X7 profile;
- one declared visual question;
- one known failure risk.

### Round-A constraints
- same approximate output format/aspect ratio across all five;
- comparable information burden;
- no route receives materially more polish than another;
- no logo-selection decision;
- no final typeface or palette freeze;
- no generated artifact becomes a reference for another route.

### Human review
For each route, collect only high-value signals:
- `PULL`
- `CURIOUS`
- `CRAFT ONLY`
- `REPEL`
- `OVERDONE`
- `UNDERDONE`
plus concise directional notes.

Expected outcome: 2–3 survivors, not a final winner.

---

## Round B — Controlled mutation
For each surviving route, create **three mutations**.

Each mutation changes **one principal dimension only**.

Examples:
- anatomical ↔ symbolic;
- revealed ↔ withheld;
- G1 ↔ G2 grotesque intensity;
- rational ↔ oneiric;
- scientific ↔ ritual;
- editorial ↔ pictorial;
- silent ↔ dramatic.

### Invalid Round-B iteration
- changing composition, palette, body treatment, surreal intensity and typography simultaneously;
- simply asking for `more premium`, `more artistic`, `more cinematic`, or `more bold`;
- using a previous generated image as a style reference without isolating the approved principle.

Expected outcome: identify which variables create genuine human affinity and which merely increase spectacle.

---

## Round C — System proof
For each surviving direction, build a **three-surface proof kit**:

1. **Expressive Hero** — maximal Brand-expression surface.
2. **Editorial / Research Surface** — real hierarchy, title, body, caption, metadata and annotation.
3. **Reduced / Operational Surface** — low imagery, restrained ornament, functional information.

A route cannot win on hero imagery alone.

### Required checks
- P0 monochrome proof;
- light-surface proof;
- source-image removal proof;
- small-scale/compression proof;
- Anti-Canon red team;
- system-fertility review.

Expected outcome: 1–2 routes with demonstrated system potential.

---

## Round D — Convergence
Only after system proof may elements from two routes be combined.

Convergence must name:
- which operation comes from Route A;
- which structural rule comes from Route B;
- what is explicitly rejected from each;
- why the combination resolves the Brand thesis better than either route alone.

Do not create a `best of everything` collage.

Expected outcome: Brand Direction candidate for downstream proof, not final Brand V1.

# 4. Mutation record schema

Every meaningful iteration records:

```text
ITERATION_ID:
ROUTE:
QUESTION:
PRESERVE:
MUTATE:
OPERATIONS:
AXIS_PROFILE_BEFORE:
AXIS_PROFILE_AFTER:
HUMAN_SIGNAL:
STRUCTURAL_RESULT:
ANTI_CANON_RISK:
DECISION: PASS / MUTATE / KILL
LEARNING:
```

The point is not bureaucracy. The record prevents circular generation and lets the project learn from rejected work.

---

# 5. Selection rubric

Do not select by prettiness alone.

Evaluate every survivor on:

1. **Human affinity** — genuine pull from the owner.
2. **Thesis legibility** — master tension is perceptible.
3. **Distinctiveness** — not interchangeable with dark creative-agency branding.
4. **Mechanism clarity** — can explain why it works without citing an artist.
5. **System fertility** — can generate multiple visual families.
6. **Functional survivability** — survives real information and business surfaces.
7. **Range** — works dark/light, image-rich/image-light, large/small.
8. **Anti-Canon distance** — visibly resists known collapse modes.
9. **Production feasibility** — can be recreated consistently without heroic manual intervention.
10. **Future extensibility** — supports signature, typography, composition, motion and Asset Factory stages.

No weighted numeric score is required unless ambiguity persists. Qualitative evidence + PASS/MUTATE/KILL is preferred.

---

# 6. Stop conditions

Stop iterating a route when any is true:

- repeated mutations no longer produce new learning;
- human response remains `CRAFT ONLY` across meaningful mutations;
- route repeatedly collapses into one Anti-Canon family;
- route only works with one historical/cinematic image;
- route fails functional/system proof;
- another route captures the same mechanism more clearly;
- owner marks `REPEL` with no preserved invariant worth testing.

Continue iterating when:
- affinity is strong but one dimension is wrong;
- route is structurally fertile but under/over-expressed;
- one operation works while another causes drift;
- the visual feels close enough that a controlled mutation can answer a specific question.

---

# 7. Human-review burden

The owner should not be asked to write design criticism for every artifact.

Useful feedback can be as small as:
- `1 pulls me more than 3`;
- `more anatomical`;
- `less ritual`;
- `this feels too Gothic`;
- `keep the composition, kill the palette`;
- `surrealism good, but quieter`;
- `this is beautiful but not mine`.

The operator translates that signal into axis/operation changes and records the mutation.

---

# 8. Phase-5 completion condition

Phase 5 closes only when:
- all five routes have been tested once;
- rejected routes have recorded learning;
- surviving route(s) have gone through controlled mutation;
- at least one direction passes the three-surface system proof;
- the owner selects or explicitly converges a direction;
- the selected direction can be described through rules without naming source artists.

Then proceed to Phase 6 — Asset Proof Kit.
