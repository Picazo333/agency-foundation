# Valid learning retained from this historical reconciliation

The following findings remain active negative/process evidence:

1. sequential generated outputs can contaminate later iterations;
2. separate labels do not guarantee structural divergence;
3. repeated dragon/wyvern morphology is invalid positive evidence;
4. full generated identity boards change too many variables simultaneously;
5. unequal boards cannot be compared fairly;
6. liturgical/manuscript influence must be structural, not pasted Gothic ornament;
7. safety-driven prompt rewriting must not silently alter the conceptual question;
8. image generation should produce ingredients, not autonomous brand systems;
9. Visual Asset Curation, Creative Direction, Taste, Brand Identity, Superdesign methodology and Figma remain the correct existing capability stack.
