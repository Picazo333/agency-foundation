# DIVINIVID — Phase 5 Anchored Derivation Plan

## Why this replaces the current next-step proposal
The last reconciliation correctly identified generation drift, but its immediate response over-isolated organism morphology. That solved one failure mode while creating another risk: treating the specimen language as if it were the Brand.

The human owner has now clarified the most important evidence:

> The earliest serious original explorations remain the strongest work produced so far. The objective is not to abandon them, but to derive from them systematically, introducing controlled contrasts until the Brand identity emerges.

Therefore Phase 5 must return to **anchored derivation**, not continue as free specimen exploration.

This is a sub-workflow inside the frozen Phase-5 gate. It does not reorder the master plan. It changes the method used to finish Phase 5 after documented drift.

---

# 1. Governing principle

`APPROVED EARLY ANCHORS → DECOMPOSE → CONTROLLED DERIVATIVES → COMPARE EQUIVALENT EVIDENCE → NARROW → SYSTEM PROOF → RETURN TO MASTER PLAN`

The important distinction is:

- **Anchor** = human-approved visual evidence.
- **Principle** = transferable mechanism extracted from the anchor.
- **Derivative** = a controlled test that changes one declared identity dimension.
- **Asset** = one ingredient, never the identity by itself.
- **Identity specimen** = an editable comparison surface proving how several approved layers behave together.

No new visual family may outrank the anchors merely because it is newer.

## Objective
Recover the exact earliest serious original explorations the human owner identifies as the best work to date and make them the visual baseline for Phase 5.

## Required artifact
Create `PHASE_5_GOLDEN_ANCHOR_MANIFEST.md` containing exactly three human-confirmed anchors:

- `GA-01`

For each anchor record:

## Hard gate
**No further derivative generation until the exact three anchor artifacts are pinned.**

If the files are only present in chat, recover/export them first. Do not approximate them from memory and do not substitute later generations.

# 3. Stage A1 — Decompose each anchor into identity DNA

Each Golden Anchor is decomposed across the same seven layers.

## L1 — Image / illustration language
- subject family;
- organic/anatomical behavior;
- surreal mechanism;
- detail register;
- representational vs abstract balance.

## L2 — Composition
- symmetry/asymmetry;
- negative space;
- scale;
- focal behavior;
- containment / invasion / revelation.

## L3 — Darkness / illumination
- darkness budget;
- semantic light;
- reveal hierarchy;
- atmosphere vs legibility.

## L4 — Liturgical / historical structure
- manuscript/marginalia behavior;
- devotional or reliquary logic;
- engraving/plate relationship;
- ceremonial framing;
- what is structural vs decorative.

## L5 — Typography behavior
Phase 5 does **not** select the final fonts. Record only:
- display register;
- body register;
- annotation/caption register;
- density;
- relationship between word/image/information.

## L6 — Color / material
- ivory / black / crimson roles;
- bone, ink, pigment, paper, membrane, engraving and shadow behavior;
- whether color is semantic or decorative.

## L7 — Information / system behavior
- editorial containment;
- annotation;
- evidence/classification;
- hierarchy;
- repeatability beyond one hero image.

For every layer mark:
- `KEEP` — already strong and should remain fixed for first derivatives;
- `TEST` — promising but unresolved;
- `DROP` — artifact-specific or known drift.

The decomposition creates the real parent. **Pixels are evidence; the layer map is the transferable design parent.**

# 4. Stage A2 — Build one comparable Anchor Specimen per Golden Anchor

Before making derivatives, assemble the three anchors into an equivalent comparison shell.

This is **not** a generated full identity board.

Each specimen uses the same slots:
1. primary approved anchor image;
2. `DIVINIVID` provisional wordmark treatment using role-level typography only;
3. one short hierarchy strip: display / heading / body / annotation;
4. one composition skeleton;
5. one liturgical/historical micro-language sample;
6. one information/annotation sample;
7. palette/material strip;
8. written `KEEP / TEST / DROP` card.

## Assembly rule
The shell is assembled/editable in Figma when available. Generation tools may produce isolated image ingredients only; they may not render the entire specimen board.

## Purpose
This restores the Brand context around the anchors without letting a generator invent typography, layout, imagery and applications in one pass.

# 5. Stage A3 — Controlled Derivation Matrix

The first derivation round creates **six children total: two per anchor**.

Why six:
- enough breadth to discover contrast;
- small enough for meaningful human comparison;
- avoids another uncontrolled 12–20 image dump.

## Four available contrast lanes
Each child moves exactly **one** primary lane. The DNA audit determines which two are most informative for each anchor.

### C1 — Oneiric / Surreal intensity
Question: can the anchor become more dream-logical and organically impossible without becoming fantasy concept art or spectacle?

### C2 — Liturgical / Manuscript structure
Question: can sacred-image, manuscript, marginalia or reliquary logic become structural without collapsing into decorative Gothic?

### C3 — Dark Revelation
Question: can concealment, silence and semantic illumination increase elegance and mystery without turning into generic black luxury?

### C4 — Editorial / System rigor
Question: can the anchor gain annotation, classification, hierarchy and repeatability without becoming clinical, SaaS-like or emotionally dead?

## Assignment rule
Do **not** apply all four lanes to all three anchors.

For each anchor choose only the two lanes with the highest expected learning value after the DNA audit.

This produces:
- `GA-01-D1`
- `GA-01-D2`
- `GA-02-D1`
- `GA-02-D2`
- `GA-03-D1`
- `GA-03-D2`

## Mutation rule
Every child must define:
- parent anchor;
- one changed layer;
- exact before/after axis change;
- all frozen layers;
- expected learning;
- known failure mode.

No child may silently change morphology, composition, palette, typography register and lighting together.

# 6. How derivatives are actually produced

The generator must not create the finished Brand direction in one shot.

For each child:

## Step 1 — Determine whether new pixels are actually required
If the variable is compositional, typographic-role or information-system based, test it through editable assembly first.

If the variable requires new imagery — e.g. oneiric matter or liturgical illustration — generate **only that ingredient**.

## Step 2 — Generate independent ingredients
When multiple ingredients are needed, each call is independent from previous generated pixels unless the owner explicitly approved an exact principle to carry forward.

## Step 3 — Curate as a set
Use Visual Asset Curation logic to reject:
- repeated underlying morphology;
- generic AI Gothic;
- pseudo-luxury;
- fantasy concept-art drift;
- aesthetically strong outliers that break the Brand universe.

## Step 4 — Assemble into the same specimen shell
Every child is compared with the same evidence burden.

No web mockup, business card, social tile or application collage is allowed in this round.

# 7. Human review protocol

Human review happens at two levels.

## Level 1 — Overall signal
- `PULL`
- `CURIOUS`
- `CRAFT ONLY`
- `REPEL`

## Level 2 — Layer signal
For L1–L7 mark only what matters:
- `KEEP`
- `MORE`
- `LESS`
- `KILL`
- free comment.

Examples:
- `PULL. Keep composition; more liturgical; less specimen.`
- `CURIOUS. Image works, typography register does not.`
- `CRAFT ONLY. Beautiful but could belong to any dark-surreal studio.`

The operator translates qualitative feedback into explicit layer/axis deltas before the next round.

# 8. Stage A4 — Broad-to-narrow funnel

The funnel is versioned and branch-like; never overwrite the parent.

## Funnel 1 — 3 anchors → 6 children
Goal: learn which contrasts increase affinity without destroying identity.

Expected survivors: 3.

## Funnel 2 — 3 survivors → 3 refined children
Create one controlled refinement per survivor based on the human's per-layer feedback.

Expected survivors: 2.

## Funnel 3 — 2 survivors → side-by-side identity proof
Do not create another freeform art round. Build equivalent identity specimens with the same shell.

Expected survivor: 1 primary direction, or an explicitly justified two-lineage convergence candidate.

## Versioning
Every meaningful branch receives a stable ID. Rejected versions remain inspectable but cannot seed later work.

This adopts the useful **broad → narrow → compare → pick** behavior found in external brand-exploration workflows while preserving DIVINIVID's stricter contamination and gate rules.

# 9. Stage A5 — Brand identity tests before Phase 5 can close

The winning survivor must pass these tests before returning to the master plan.

## T1 — Brand Without Beast
Remove all creature/organism imagery.

Must remain recognizably DIVINIVID through:
- composition;
- typography behavior;
- color/material;
- liturgical/historical structure;
- annotation/information;
- darkness/revelation.

If identity collapses, the specimen is carrying the Brand and the direction fails/mutates.

## T2 — Beast Without Brand
Remove wordmark, composition shell, annotation and Brand structure.

If the image could belong unchanged to many unrelated dark-surreal projects, classify it correctly as **asset language**, not Brand identity.

This is acceptable only if T1 passes.

## T3 — Image Removal
Replace primary image with a neutral block. Hierarchy and composition must still work.

## T4 — Monochrome
No dependence on crimson for identity recognition.

## T5 — Light Surface
The system must survive ivory/light surfaces; darkness cannot be the only carrier.

## T6 — Small Scale
Recognizable rhythm and hierarchy at compressed size.

## T7 — Anti-Canon
Must not read as:
- generic dark agency;
- occult brand;
- Gothic luxury;
- fantasy studio;
- dark-tech / neon;
- historical pastiche;
- Swiss-grid spectacle with medieval decoration pasted on top.

## T8 — System Fertility
The rules must generate at least three distinct artifacts without repeating one hero composition.

# 12. External workflow precedent review

A bounded GitHub search found three useful precedents.

## HermeticOrmus / design-mastery-claude-code — Brand Identity Builder
- MIT licensed.
- Useful pattern: explicit discovery → visual directions → refinement → documentation.
- Useful here: refinement must follow narrowed directions rather than endless free generation.
- Intake decision: **do not add as a competing Brand Identity authority** because the repository already has a stronger approved Brand Identity skill. Use only as process corroboration.

## Roxabi / Brand Exploration Playbook
- AGPL-3.0 and dependency-heavy.
- Useful pattern: parallel divergence, founder convergence gates, then versioned broad→narrow asset iteration.
- Particularly useful idea: per-dimension feedback is more valuable than whole-board preference.
- Intake decision: **do not vendor/install**. Integrate only generic orchestration lessons into this local plan; avoid license/dependency surface.

## Jinstronda / design-with-ai
- Strong `inspect before inventing`, reference-first, controlled-slices, explicit-refinement workflow.
- No repository license found during intake check.
- Intake decision: **do not vendor/install** without a clear license. The already-approved Taste + Impeccable + Creative Direction stack covers the required quality behavior.

## Capability conclusion
`USE_EXISTING + LOCAL ORCHESTRATION`.

The bottleneck was not lack of design skills. It was failure to orchestrate them around human-approved anchors.

# 13. Success criteria for the corrected Phase 5

Phase 5 may close only when all are true:

1. exact Golden Anchor Set A is pinned;
2. all three anchors have a seven-layer DNA map;
3. all first-round derivatives share the same comparison shell;
4. every derivative changes one principal contrast only;
5. at least one direction improves human pull without losing anchor identity;
6. repeated morphology/composition is rejected unless explicitly the tested constant;
7. liturgical influence is structural when present;
8. Dark Revelation changes information/revelation behavior, not merely exposure;
9. typography remains provisional role evidence;
10. the primary survivor passes Brand Without Beast;
11. asset imagery is correctly separated from identity structure;
12. the winner is fertile across multiple artifacts;
13. all rejected work is recorded as negative evidence;
14. the selected direction can be explained without naming source artists;
15. human owner explicitly `PASS`es the survivor or approves a named convergence.
