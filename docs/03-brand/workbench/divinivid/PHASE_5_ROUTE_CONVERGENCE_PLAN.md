# DIVINIVID — Phase 5 Route Convergence Plan

## Objective
Move from five approved visual territories to a controlled identity convergence without repeating the failure modes of earlier rounds: route contamination, repeated morphology, premature applications, unbalanced comparison boards, or aesthetic selection based only on one hero image.

The route set is now evidence-rich enough to stop inventing new territories.

The work changes from **route discovery** to **mechanism selection and controlled convergence**.

---

# 1. Fixed route set

- `R1 — Dark Revelation`
- `R2 — Bestiary of Systems`
- `R3 — Sacred Corporeal`
- `R4 — Oneiric Anatomy`
- `R5 — Illuminated Marginalia`

All five routes have approved Moodboard I + Moodboard II.

No Route 06 may be opened unless the human owner explicitly reopens divergence after a documented failure of the five-route set.

---

# 2. Stage C0 — Normalize route evidence

## Goal
Convert each approved two-board pair into one comparable Route Dossier.

## Required Route Dossier structure
Every route receives the same fields:

1. **THESIS** — one sentence;
2. **L1 Image / illustration language**;
3. **L2 Composition**;
4. **L3 Darkness / illumination**;
5. **L4 Liturgical / historical structure**;
6. **L5 Typography behavior**;
7. **L6 Color / material**;
8. **L7 Information / system behavior**;
9. **Graphic devices / micro-language**;
10. **Motion behavior**;
11. **Reduced-state behavior**;
12. **Anti-pattern / NO-LEAK rules**;
13. **Strongest human signal**;
14. **Known route risk**.

## Output
`PHASE_5_ROUTE_DNA_MATRIX.md`

## Gate
All five routes must carry equivalent evidence. No route gets extra polish, more application examples or additional image slots during comparison.

# 3. Stage C1 — Baseline parameter map

Use the existing Phase-5 controls. Do not invent a new slider vocabulary unless a real missing dimension is found.

## Existing axes
- `X1 Anatomical ↔ Symbolic`
- `X2 Revealed ↔ Withheld`
- `X3 Grotesque intensity`
- `X4 Rational ↔ Oneiric`
- `X5 Scientific ↔ Ritual`
- `X6 Editorial ↔ Pictorial`
- `X7 Silent ↔ Dramatic`
- `X8 System ↔ Hero`
- `X9 Human ↔ Specimen`

Each route receives a baseline vector derived from its two approved boards.

The vector is descriptive, not a score of quality.

## Additional non-slider constraints
Track separately:
- `HISTORICAL_VISIBILITY`;
- `LITURGY_STRUCTURALITY` — structural vs decorative;
- `ORNAMENT_BUDGET`;
- `CRIMSON_BUDGET`;
- `DARKNESS_BUDGET`;
- `HERO_DEPENDENCE`;
- `SAFETY_RISK` where relevant.

## Gate
The human owner confirms that the baseline vectors approximately describe the routes before any derivative generation begins.

# 4. Stage C2 — Comparative review

## Goal
Determine what should survive from each route without prematurely declaring one complete route the winner.

### Route-level signal
For each route:
- `PRIMARY PULL`
- `SECONDARY PULL`
- `USE AS DONOR`
- `HOLD`
- `KILL`

### Layer-level signal
For every L1–L7 layer:
- `KEEP`
- `BORROW`
- `TEST`
- `LESS`
- `KILL`

### Important current signal
`R4 — Oneiric Anatomy` enters C2 with **strongest stated current inclination**, but receives the same evidence burden and stress tests as the others.

## Selection target
Advance **three parent directions**.

A parent direction may be:
- one intact route;
- or one route with a clearly named donor mechanism from another route.

A parent may never be “a little of everything.”

---

# 5. Stage C3 — Controlled contrast mutations

## Goal
Learn which borrowed mechanisms materially improve each selected parent.

### Quantity
- 3 parent directions;
- 2 controlled children per parent;
- **6 mutation boards total**.

### Mutation rule
Each child changes **one principal mechanism only**.

Examples of valid mutations:
- Oneiric Anatomy + Dark Revelation's semantic conceal/reveal behavior;
- Oneiric Anatomy + Illuminated Marginalia's structural page/margin logic;
- Sacred Corporeal + stronger editorial-system rigor;
- Bestiary + stronger ritual framing while morphology remains frozen.

Examples are illustrative only. Final donor lanes are selected after C2.

### Forbidden mutation behavior
A single child may not simultaneously:
- change subject family;
- change typography register;
- change composition;
- change palette;
- change image-treatment logic;
- and change liturgical intensity.

If more than one major mechanism changes, the child is invalid comparison evidence.

---

# 6. Mutation Board contract

A mutation board is not another full freeform moodboard.

Every one uses the same comparison shell:

1. parent route ID + donor mechanism;
2. one primary identity image/ingredient;
3. one typography-in-use strip;
4. one composition proof;
5. one material/color strip;
6. one graphic-device strip;
7. one reduced state;
8. one web/interface fragment only;
9. mutation card showing `CHANGED / FROZEN / EXPECTED LEARNING / FAILURE RISK`.

## Why one web fragment is allowed here
At this checkpoint, both Moodboard-II boards already proved each route has system ambitions. A single equivalent web fragment is now useful as comparable evidence, but full homepage/application collages remain prohibited.

---

# 7. Generation discipline

## One route at a time
Generate and review children independently.

## No accidental visual parenting
A previous child image is not a style reference for the next child unless explicitly approved.

## Route packet only
Every generation receives:
- DIVINIVID master thesis;
- parent Route Dossier;
- one mutation card;
- the parent route's NO-LEAK list;
- global anti-canon.

It does **not** receive full descriptions of all five routes.

## Set-level curation
Before human review, reject outputs showing:
- route contamination;
- repeated underlying composition;
- generic AI Gothic;
- dark-luxury drift;
- occult branding;
- fantasy concept art;
- cyan/neon/dark-tech;
- literal anatomical gore;
- visual complexity without identity function.

---

# 8. Stage C4 — First convergence

From six mutations select **three survivors**.

Selection is based on:
- human pull;
- thesis fidelity;
- distinctiveness;
- system fertility;
- image/identity separation;
- typography/composition compatibility;
- ability to work light and dark;
- B2B credibility;
- anti-canon resilience;
- production feasibility.

No arithmetic score automatically selects the winner. Any numeric matrix is diagnostic only; the human creative owner makes the promotion decision.

---

# 9. Stage C5 — Refinement round

Produce **one refinement per survivor** based only on explicit human feedback.

Three refinements total.

Each refinement must state:
- what is now locked;
- what is increased;
- what is reduced;
- what remains unresolved.

Expected survivors after review: **two**.

---

# 10. Stage C6 — Two-direction System Proof

The final two directions receive equivalent system proofs.

Each proof contains editable evidence for:

1. wordmark behavior at role level — not final logo;
2. display / body / annotation hierarchy;
3. light and dark surface;
4. image-rich hero surface;
5. image-poor editorial surface;
6. reduced operational surface;
7. one information-dense surface;
8. graphic devices;
9. material/texture behavior;
10. motion keyframes;
11. mobile/compressed state;
12. one no-image state.

Figma becomes preferred editable assembly source when access is available.

Image generators supply ingredients only.

---

# 11. Stage C7 — Adversarial identity tests

Both finalists run the same tests.

## T1 Brand Without Hero
Remove the primary image. Identity must remain recognizable.

## T2 Image Swap
Replace the hero with a neutral unrelated image treatment-compatible asset. The system must not collapse.

## T3 Monochrome
Remove crimson and gold. Identity should still possess structure.

## T4 Light Surface
Must work on ivory/light background.

## T5 Dark Surface
Must work on dark background without becoming generic dark luxury.

## T6 Small Scale
Test compressed card/mobile/navigation contexts.

## T7 Information Density
Test long-form / research / case-study content.

## T8 Anti-Canon
Must not read as occult, fantasy, dark-tech, gothic luxury, generic AI surrealism or medieval cosplay.

## T9 Distinctive Without Historical Costume
Reduce visible historical ornament. Core identity must survive.

## T10 Fertility
Create at least three materially different artifacts without repeating the same hero composition.

---

# 12. Stage C8 — Human convergence gate

Possible outcomes:

### PASS — one direction
One finalist becomes the Phase-5 selected territory mechanism and proceeds to Phase 6.

### CONVERGENCE — named two-lineage synthesis
Allowed only when the human owner can state precisely which layers come from each parent and why the resulting system is more coherent than either source alone.

### MUTATE
One additional targeted test is allowed if a single unresolved variable blocks selection.

### KILL / reopen
Only if both finalists fail system proof. Do not reopen all five routes casually.

# 13. Handoff after Phase 5

Phase 5 still does not finalize the Brand system.

After convergence:
- **Phase 6 — Asset Proof Kit** proves image/illustration families;
- **Phase 7 — Signature System** develops DIVINIVID wordmark/symbol logic;
- **Phase 8 — Foundations** finalizes typography, palette, tokens and accessibility;
- **Phase 9 — Composition Grammar** formalizes modes;
- **Phase 10 — Image / Illustration Language** formalizes usage rules;
- later phases cover motion, digital specimen, applications and stress tests.

This preserves the frozen master-plan sequence.

# 14. Working cadence / repository policy

During visual iteration:
- do **not** write to GitHub after every generation;
- keep conversational visual exploration fast;
- update the repo only at meaningful promotion/rejection checkpoints.

Recommended repository checkpoints:
1. current five-route checkpoint — NOW;
2. after C2 when three parents are selected;
3. after C4 when three mutation survivors are selected;
4. after C6 when two system-proof finalists are ready;
5. final Phase-5 PASS / convergence.

This keeps GitHub as the decision record rather than a generation log.
