# DIVINIVID — Visual Grammar V0

> **Phase 4 — Tension Grammar**
>
> Purpose: stop designing from artists and start designing from rules.
>
> This document translates the Phase 1 Creative Direction Contract and the Phase 3 Reference Atlas into a generative grammar for original DIVINIVID visual work. It is intentionally pre-foundation: no final typeface, logo, palette or production asset is approved here.

---

# 1. Core proposition

DIVINIVID should not look like a collage of historical references. It should behave like a contemporary system in which opposed states can coexist without neutralizing each other.

The preferred perceptual sequence remains:

`BEAUTY / ORDER → ANOMALY / DISTURBANCE → RECONCILIATION`

and temporally:

`REVEAL → DISTURB → RECONCILE`

The Phase 3 human gate sharpens the visual center of gravity to:

`GROTESQUE / CORPOREAL + DARKNESS / REVELATION + ANATOMICAL ORDER + SURREAL MODULATION`

This is not a style stack. It is a set of interacting rules.

---

# 2. Design axioms

## A1 — Order must precede anomaly
Strangeness is strongest when the viewer first perceives a coherent system.

**Implication:** anatomy, frame, hierarchy, grid, inscription, classification, or compositional calm should normally establish a legible order before deformation or impossible relation is introduced.

**Reject when:** the first read is already chaotic.

## A2 — Darkness stores information
Darkness is not decoration or generic dark mode. It withholds, compresses, or delays meaning.

**Implication:** use dark fields, occlusion, near-black material, cropping, silence, or temporal delay to make later revelation semantically meaningful.

**Reject when:** everything is black merely to feel serious.

## A3 — Light reveals, it does not embellish
Illumination must disclose hierarchy, body, evidence, symbol, or transformation.

**Reject when:** glow, bloom, bright pigment or white space has no semantic target.

## A4 — The body is a knowledge object and a symbolic object at once
Anatomy is not just visual texture. It can carry evidence, mortality, classification, vulnerability, transcendence and uncanny recognition.

**Reject when:** anatomical content functions as decorative medical wallpaper.

## A5 — The grotesque belongs inside a system
Meaningful anomaly should remain relational to the order it disturbs.

**Reject when:** monsters, deformity or body horror become autonomous spectacle.

## A6 — Surrealism is controlled dislocation
The surreal enters by changing relationship, context, scale, sequence, repetition, spatial logic or bodily possibility — not by spraying unrelated dream symbols.

**Reject when:** the image would be described as “random weird stuff”.

## A7 — Historical intelligence must survive abstraction
A source may be explicit, but the identity must still function when the source image is removed.

**Reject when:** the artifact becomes generic as soon as the engraving/manuscript/film still disappears.

## A8 — Quiet is structural
Controlled maximalism requires calm fields that make concentrated intensity legible.

**Reject when:** every region competes for attention.

## A9 — Contemporary means system behavior, not trend styling
Responsiveness, accessibility, precision, motion logic and hierarchy make the system contemporary.

**Reject when:** currentness is communicated mainly by brutalism, bento, cyber-tech, glass or other fashion tropes.

## A10 — Reconciliation is the end condition
A DIVINIVID artifact should not finish as unresolved collage. The opposed elements must feel intentionally co-governed by the same visual system.

# 3. Primary visual operations

Each operation follows:
`INPUT CONDITION → ACTION → RESULT → LIMIT`

## 3.1 CONTAIN
**Definition:** place anomaly inside an explicit rational or ceremonial structure.

**Input:** coherent anatomical plate, grid, frame, taxonomic field, ritual border, diagram, inscription.

**Action:** introduce one meaningful violation inside that structure.

**Result:** `ORDER ↔ ABERRATION` becomes legible without losing hierarchy.

**Examples of valid behavior:**
- an anatomically precise figure contains one impossible organ relation;
- a bestiary-like creature occupies a classified plate rather than a fantasy scene;
- a strict editorial field contains one bodily interruption.

**Limits:**
- one primary anomaly per focal system by default;
- avoid equal-weight anomalies distributed everywhere;
- no gore-first violation.

**Failure mode:** chaos masquerading as grotesque.

---

## 3.2 INVADE
**Definition:** allow a secondary material, pigment, body, shadow, annotation or organic structure to cross the boundary of an established system.

**Input:** stable ordered field.

**Action:** let another logic enter from margin, cut, seam, shadow or internal boundary.

**Result:** the order remains readable while visibly under pressure.

**Useful pairings:**
- monochrome anatomy invaded by one semantic pigment;
- scientific engraving invaded by marginal living matter;
- clean typography invaded by a controlled anatomical contour;
- ivory field invaded by darkness rather than defaulting to full dark mode.

**Limits:** invasion should have a direction and source. Avoid “texture everywhere”.

**Failure mode:** distressed/grungy styling with no semantic event.

---

## 3.3 REVEAL
**Definition:** disclose meaning through selective illumination, cropping, exposure, contrast, opening or temporal emergence.

**Input:** concealment, darkness, silence, incomplete body, withheld diagram, neutral field.

**Action:** reveal only the information that deserves focal significance.

**Result:** `DARKNESS ↔ LIGHT` and `KNOWLEDGE ↔ MYSTERY` become narrative rather than decorative.

**Valid forms:**
- localized light on a body/diagram;
- one saturated pigment appearing after monochrome order;
- a cut revealing anatomy beneath a calm surface;
- motion that exposes rather than merely animates.

**Limits:** revelation must change interpretation or hierarchy.

**Failure mode:** cinematic lighting applied as generic drama.

---

## 3.4 MIRROR
**Definition:** place two apparently opposed states into an explicit structural equivalence.

**Input:** body/cosmos, sacred/grotesque, human/creature, interior/exterior, rational/oneiric, life/death.

**Action:** share geometry, axis, framing, pose, rhythm, proportion or annotation logic.

**Result:** difference remains visible, but the viewer perceives a common underlying system.

**Valid forms:**
- anatomical and celestial diagrams share one geometry;
- two bodies/figures echo one pose at different ontological states;
- mirrored word/mark behavior expresses the palindrome without gimmickry.

**Limits:** avoid obvious split-screen “before/after” clichés.

**Failure mode:** symmetry without conceptual relation.

---

## 3.5 TRANSFORM
**Definition:** move one element between states while preserving enough continuity that the transformation remains intelligible.

**Input:** stable object, body, glyph, diagram, material or image state.

**Action:** alter anatomy, material, scale, pigment, geometry, visibility or semantic role progressively.

**Result:** the artifact dramatizes coexistence as a process rather than a static juxtaposition.

**Valid forms:**
- anatomical plate becomes symbolic architecture;
- scientific linework slowly becomes creature or landscape;
- body transitions into inscription/diagram without losing structural continuity;
- motion passes from concealment to legibility to altered meaning.

**Limits:** preserve one invariant through the change: axis, contour, rhythm, grid, or identifiable object logic.

**Failure mode:** morphing for spectacle.

---

## 3.6 RECONCILE
**Definition:** construct a final state in which competing visual logics remain distinct but clearly belong to one system.

**Input:** at least two tension poles already made visible.

**Action:** establish a common hierarchy, material rule, axis, frame, rhythm, palette role, or narrative logic.

**Result:** tension feels intentional, not pasted together.

**This is the terminal operation** for major brand artifacts.

**Limits:** reconciliation must not erase difference. If everything becomes stylistically uniform, the tension has been neutralized.

**Failure mode:** generic harmony that loses the unsettling charge.

---

## 3.7 DISLOCATE — surreal operation under test
**Definition:** move a body, object, scale, sequence, context, repetition or spatial relation away from expected reality while preserving compositional discipline.

**Input:** a recognizable object/system and an established expectation.

**Action:** alter one relational rule.

**Examples:**
- anatomical object appears at architectural scale;
- a precise body plate occupies an impossible spatial setting;
- a familiar object repeats with ritual rather than physical logic;
- a body relation is anatomically impossible but graphically exact;
- an object appears in a context that changes its symbolic function.

**Result:** `FAMILIAR ↔ IMPOSSIBLE` becomes an uncanny secondary tension that amplifies the five master tensions.

**Limits:**
- one primary dislocation per focal event unless a later experiment proves greater density works;
- the displaced object must remain legible enough for expectation to be violated;
- no random dream-object accumulation;
- no surrealism that weakens the solemn/ritual register into whimsy.

**Failure mode:** AI-weirdness, kitsch surrealism, visual joke, or collage without hierarchy.

**V0 status:** `CANDIDATE → TEST IN PHASE 5`.

# 4. Cross-cutting surreal modulation

Surrealism is not limited to `DISLOCATE`. It may modulate other operations:

| Base operation | Surreal modulation |
|---|---|
| CONTAIN | the contained anomaly obeys graphic logic but violates physical logic |
| INVADE | the invading matter changes ontological category, not just texture |
| REVEAL | the revealed content changes the meaning of the containing scene/system |
| MIRROR | the mirrored pair shares structure while belonging to incompatible realities |
| TRANSFORM | transformation follows dream continuity instead of physical continuity |
| RECONCILE | impossible elements share one rigorous compositional law |

### Surrealism ceiling
For Brand/editorial exploration, surrealism can be prominent. For proposals, research, procurement and operational UI, it should normally reduce to H0/H1-equivalent behavioral traces: crop, relation, motion, annotation or subtle spatial contradiction.

The Brand must remain usable without explicit surreal imagery.

# 5. Preferred domain grammar

## 5.1 Light
**Rule:** darkness is the field; illumination identifies meaning.

Use:
- local revelation;
- hard/decisive focal contrast;
- pigment as semantic light;
- quiet ivory fields as an inverse form of illumination.

Avoid:
- neon glow;
- ambient bloom;
- purple/cyan tech lighting;
- uniform cinematic grading.

---

## 5.2 Color
**Default proof:** P0 monochrome must work.

Preferred expressive territories:
- ink / charcoal;
- ivory / bone / paper whites;
- carmine / vermilion / crimson as high-signal event;
- ultramar as historically intelligent counterpoint where justified;
- aged metallic/gold as material/ritual event, never default luxury coding.

Surrealism may intensify color relationships but may not justify arbitrary multicolor palettes.

---

## 5.3 Body
Preferred body roles:
1. **evidence** — anatomical/scientific;
2. **threshold** — living ↔ dead, human ↔ transcendent;
3. **system** — measured, sectional, annotated;
4. **symbol** — body relation carries conceptual meaning;
5. **uncanny object** — recognizable body logic is subtly displaced.

Avoid:
- glossy medical 3D;
- eroticized anatomy without explicit concept;
- gore;
- generic AI body distortion.

---

## 5.4 Grotesque
Preferred grotesque:
- hybrid but interpretable;
- historically or anatomically grounded;
- contained within hierarchy;
- meaningful to the surrounding system.

Preferred intensity in Phase 5 exploration: **G1–G3**, with G3 isolated and deliberate.

---

## 5.5 Geometry
Preferred sources of geometry:
- anatomical axes;
- bilateral / palindromic logic;
- plate framing;
- diagram circles/arcs/section lines;
- manuscript center/margin relationships;
- architectural aperture and void.

Geometry exists to organize tension, not to produce a fashionable grid aesthetic.

---

## 5.6 Composition
Every major exploratory composition should attempt:
1. one obvious primary event;
2. one subordinate system of evidence/detail;
3. one quiet recovery zone.

Preferred asymmetry: controlled and tension-bearing.

Preferred symmetry: only when mirroring, ritual, anatomy or palindrome mechanics justify it.

---

## 5.7 Texture / material
Allowed roles:
- evidentiary age/materiality;
- print/engraving behavior;
- paper, ink, pigment or dark tactile field;
- boundary between states.

Texture should not be a distressed overlay applied globally.

---

## 5.8 Annotation / information
This is a major opportunity for distinctiveness.

Preferred:
- folio logic;
- specimen/plate labels;
- sectional markers;
- captions as evidence;
- marginal notes;
- diagram numbering;
- inscriptions integrated into image structure.

Annotation must remain legible and useful. It cannot become fake scientific lorem ipsum.

---

## 5.9 Symbolism
Symbols should emerge from:
- body;
- object relation;
- source-derived iconography;
- repeated structural operations;
- palindrome / bilateral mechanics;
- transformation.

Avoid generic occult icons, tarot shorthand, zodiac, random eye motifs and synthetic sigils.

---

## 5.10 Motion
Preferred motion verbs:
- uncover;
- emerge;
- split;
- align;
- mirror;
- breathe minimally;
- transform;
- invade;
- recede;
- resolve.

Avoid:
- particles;
- glitch;
- cyber scanlines;
- decorative parallax with no narrative role;
- excessive elastic movement.

---

## 5.11 Narrative
Preferred sequence:
`ORIENT → WITHHOLD → REVEAL → DISTURB → REFRAME → RECONCILE`

Not every surface needs the full sequence. Hero/campaign/motion may use it; operational UI may use only orient/reveal.

---

## 5.12 Density
Density should be **localized**.

Dense zones may contain:
- engraving;
- anatomy;
- marginalia;
- concentrated annotation;
- controlled surreal event.

Quiet zones preserve:
- copy readability;
- hierarchy;
- utility;
- emotional pacing.

# 6. Control axes for Phase 5 iteration

Every Phase 5 artifact should record its position on these seven axes using a 0–4 qualitative scale.

## X1 — Anatomical ↔ Symbolic
`0 = strictly anatomical/evidentiary`
`4 = body primarily symbolic/metaphysical`

## X2 — Revealed ↔ Withheld
`0 = fully exposed/light`
`4 = high concealment / delayed revelation`

## X3 — Grotesque intensity
Maps to existing `G0–G3`; `G4` remains prohibited.

## X4 — Rational ↔ Oneiric
`0 = physically/rationally coherent`
`4 = highly dream-logical but compositionally controlled`

## X5 — Scientific ↔ Ritual
`0 = plate/lab/treatise logic`
`4 = ceremonial/iconic/ritual logic`

## X6 — Editorial ↔ Pictorial
`0 = typography/information structure dominates`
`4 = image/atmosphere dominates`

## X7 — Silent ↔ Dramatic
`0 = restrained, quiet tension`
`4 = confrontational visual event`

### Constraint
No route may simply max all axes. Distinctiveness must come from a deliberate profile.

# 7. Hard anti-rules

Global rejects remain:
- cyan/neon/cyber-dark;
- pseudo-luxury black + gold + serif;
- dark academia;
- generic AI Gothic;
- occult shorthand;
- videogame/fantasy medieval;
- medical futurism;
- uniform parchment/blackletter pseudo-medievalism;
- gore / shock-first body horror;
- trend-brutalist agency styling;
- random surreal collage;
- decorative complexity without hierarchy.

Additional Phase 4 rejects:
- direct imitation of a named artist;
- anatomy used only as texture;
- surrealism used only to appear creative;
- “mystery” that hides weak information architecture;
- a composition that cannot explain which operation it is using.

# 10. Evaluation rubric for original visual iterations

Do not score for prettiness. Every candidate is reviewed on six questions:

## E1 — Thesis legibility
Can a reviewer perceive at least one master tension without explanation?

## E2 — Mechanism clarity
Can the operator identify which grammar operation(s) are producing the effect?

## E3 — Distinctiveness
Does the work avoid the Anti-Canon and generic creative-agency styling?

## E4 — System fertility
Can the mechanism plausibly produce multiple assets/surfaces without repeating one hero image?

## E5 — Contemporary viability
Can the mechanism survive typography, information, responsiveness and functional surfaces?

## E6 — Human affinity
Does the creative owner experience genuine pull rather than merely acknowledging craft?

### Decision semantics
- `PASS` — mechanism deserves a controlled next iteration.
- `MUTATE` — useful learning, but one or more parameters must change.
- `KILL` — mechanism is weak, generic, off-thesis or structurally infertile.

A visually attractive `KILL` remains killed.

---

# 11. Iteration protocol for Phase 5

The purpose of Phase 5 is **discovery through controlled visual iteration**, not first-shot finality.

For each of the five routes:
1. generate/build an initial coherent hypothesis;
2. record its axis profile and operations;
3. human reviews for affinity and failure signals;
4. mutate only the dimensions implicated by feedback;
5. preserve successful invariants;
6. record why rejected variants failed;
7. continue until the route either demonstrates system potential or is killed.

### Important rule
Do not generate endless variants. Every new iteration must answer a specific question.

Examples:
- more anatomical vs more symbolic?
- more withheld vs more revealed?
- more oneiric vs more rational?
- stronger grotesque vs subtler anomaly?
- more scientific vs more ritual?

If a new image does not test a declared variable, it should not be generated.

# 12. Gate tests for Phase 4

Phase 4 may close when all are true:

1. a designer can create a relevant artifact using this grammar without seeing the source artists;
2. every proposed Phase 5 route has a distinct operation stack and axis profile;
3. surrealism has explicit rules and limits rather than vague permission;
4. Vesalian/anatomical preference has been translated into structural rules, not artist imitation;
5. the grammar includes hard rejection criteria for Anti-Canon drift;
6. at least one route can succeed with minimal/no historical imagery;
7. the grammar supports both dark and light-surface behavior;
8. the human creative owner approves the grammar as the basis for original visual production.
