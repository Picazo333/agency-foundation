# PLAN_DEVIATION — Phase 3 Figma Backfill

## Reason
The frozen visual-identity master plan designates Figma as the editable visual source of truth for Reference Atlas assembly. During Phase 3, the connected Figma Starter plan reached its MCP tool-call quota after the six board structures, labeled slots, acquisition-state overlays and source-staging panels had been created. Additional image placement and screenshot verification became unavailable.

The human owner explicitly chose to continue the work outside Figma rather than pause the entire Brand program. A source-only HTML review artifact was therefore used to obtain directional feedback while preserving Figma as the eventual editable visual source of truth.

## Evidence
Before quota exhaustion, Figma contained:
- five positive Reference Atlas board structures;
- one Anti-Atlas structure;
- labeled source slots;
- source-acquisition status overlays;
- verified-source staging / provenance links;
- the remaining acquisition queue.

It did **not** contain the final source-image population. External review artifacts therefore supplied the visual comparison layer needed for the human gate.

## Impact
This changes the **temporary review medium**, not:
- Brand / route hierarchy;
- central thesis;
- source-only doctrine;
- reference rights requirements;
- human gate authority;
- Phase 4 or later quality requirements;
- Figma's role as editable visual source of truth for the operational identity system.

## Human approval
The human owner reviewed the external source-only boards, supplied explicit mutations and approved continuing into Phase 4 while Figma access remains constrained.

## Bounded exception
Phase 3 may close for abstraction and Phase 4 may proceed.

However, before the program treats the Atlas itself as a fully editable archival artifact, Figma must be backfilled when access is available:
1. transfer the retained source surrogates into the existing labeled slots;
2. replace/recrop unclear Board-01 references;
3. include the Phase-3 human feedback and surrealism addendum;
4. preserve rights/provenance metadata;
5. capture a final Atlas overview for archival traceability.

This backfill is **not** permission to reopen Phase 3 creatively unless the spatial assembly reveals a material contradiction.

## Stop condition
This deviation expires when the Figma Atlas has been backfilled and verified. No later phase may cite the empty pre-backfill Figma boards as if they were the approved visual evidence.
