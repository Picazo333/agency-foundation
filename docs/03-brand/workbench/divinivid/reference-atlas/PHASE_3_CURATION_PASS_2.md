# DIVINIVID Reference Atlas — Phase 3 Curation Pass 2

## Purpose
Convert the Pass-1 survivor pools into **specific source-object manifests** that are ready for visual assembly. This pass deliberately does **not** spend Figma calls on unresolved source selection.

Figma becomes necessary only after the selected object set, provenance root and rights state are explicit enough that spatial comparison can change a decision.

## Figma trigger policy
Use Figma when the unresolved question is one of:
- image scale / visual weight;
- proximity / contrast between references;
- rhythm / density / negative space;
- board-level color balance;
- visual overlap between boards;
- whether the set communicates its thesis without explanatory prose.

Do **not** use Figma for:
- choosing which source survives;
- rights/provenance bookkeeping;
- `EXTRACT / DO NOT EXTRACT` reasoning;
- candidate redundancy cuts;
- naming, copy, or textual synthesis.

The current pass resolves those non-spatial questions first.

# Board 05 — RECONCILIATION

## Art-direction statement
**DIVINIVID does not juxtapose opposites. It designs the mechanism that lets both remain true at the same time.**

## Final object set for assembly (10)

1. **Isenheim Altarpiece — multi-state system / Resurrection + Crucifixion relationship**
   - Mechanism: `TRANSFORM + RECONCILE`
   - Sacred system contains difficult flesh and changes state without abandoning either pole.

2. **Hours of Catherine of Cleves — sacred center / inventive border**
   - Mechanism: `CONTAIN`
   - Stable sacred hierarchy contains local material/strange invention.

3. **Schongauer — Saint Anthony Tormented by Demons**
   - Mechanism: `CONTAIN + INVADE`
   - Calm center remains intact under grotesque pressure.

4. **The Color of Pomegranates**
   - Mechanism: `RECONCILE`
   - Spiritual gravity survives saturated color and tactile abundance.

5. **Macario**
   - Mechanism: `RECONCILE`
   - Material everyday life and metaphysical presence share one sober world.

6. **Pierre Soulages — Outrenoir**
   - Mechanism: `REVEAL`
   - Black itself becomes the means by which light appears.

7. **Bruder Klaus Field Chapel**
   - Mechanism: `CONTAIN + REVEAL`
   - Material darkness creates the condition for a singular opening of light.

8. **Andreas Cellarius — Harmonia Macrocosmica**
   - Mechanism: `MIRROR + RECONCILE`
   - rigorous information and ornament/polychromy coexist without cancelling each other.

9. **William Blake — Book of Job**
   - Mechanism: `CONTAIN + RECONCILE`
   - divine, monstrous, textual and diagrammatic registers inhabit one disciplined page system.

10. **Bill Viola — The Crossing**
   - Mechanism: `TRANSFORM`
   - one stable body is acted on by opposing forces over time; identity can reconcile opposites temporally rather than by static collage.

## Candidate operation vocabulary
These remain `CANDIDATE`, not canon until Phase 4 abstraction:
- `CONTAIN`
- `INVADE`
- `REVEAL`
- `MIRROR`
- `TRANSFORM`
- `RECONCILE`

## Distinctive contribution
Board 05 is the synthesis board. It should make the thesis visible even if the viewer does not know any source names.

# Cross-board redundancy audit

Intentional repeats are allowed only when the same source demonstrates a **different mechanism**:
- Isenheim: illumination / corporeal suffering / reconciliation;
- Catherine of Cleves: pigment / page system / reconciliation;
- Blake: sacred illumination / grotesque containment / information architecture / reconciliation;
- Vesalius: corporeal knowledge / information order;
- Bruder Klaus: divine light / darkness field / reconciliation.

If visual assembly makes repeated references feel like one dominant style rather than cross-mechanism evidence, reduce repetition before Phase-3 closure.

- Moreau — hold; decadent/luxury gravity too strong.
