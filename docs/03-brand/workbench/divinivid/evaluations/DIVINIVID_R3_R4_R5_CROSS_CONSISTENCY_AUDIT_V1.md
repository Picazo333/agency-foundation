# DIVINIVID R3/R4/R5 Cross-Consistency Audit V1

## 0. Purpose

Test whether the newly formalized:
- R3 Composition Grammar;
- R4 Image / Illustration Language;
- R5 Temporal Identity

can operate as one system without forcing an executor to invent contradictory identity rules.

This audit does not approve P6.
It prepares the System Formalization Gate.

## 1. Audit method

Three required pairs:
1. Composition <-> Image;
2. Composition <-> Motion;
3. Image <-> Motion.

Adversarial checks also target:
- P2 Minimal / No-Icons contamination;
- R2 foundation drift;
- historical/pastiche regression;
- B0 Bestiary leakage;
- generic dark-luxury / medical / cyber drift;
- accessibility and reduced-motion conflict.

Severity:
- CRITICAL — blocks System Formalization Gate;
- MATERIAL — requires bounded mutation before gate;
- CLARIFICATION — can be adjudicated without reopening locked identity;
- NONE — compatible as written.

## 2. Composition <-> Image

### 2.1 Contemplative
Result: PASS.

R3 requires sparse singular presence and large recovery fields.
R4 supplies Celestial Mass, Membrane/Void, Porous Marrow and other families that can operate as one dominant event.

No family is mandatory.

### 2.2 Editorial / Systemic
Result: PASS.

R3 allows type and matter to be co-primary.
R4 families can function as evidence, interruption or primary matter without forcing image dominance.

P2 remains the constraint on annotation.

### 2.3 Anatomical / Topographic
Result: PASS.

Strong compatibility with:
- Porous Marrow;
- Geological Strata;
- Topographic/Coastal;
- Membrane/Void;
- Printed Evidence treatment.

The family contracts explicitly reject literal medical-brand shorthand.

### 2.4 Information-Dense
Result: PASS WITH CLARIFICATION.

R3 correctly makes information primary and matter subordinate.
R4 must not be interpreted as requiring a hero image on every dense surface.

**Binding clarification:** an R3 mode may use zero R4 image families when the application constraint requires minimal imagery. Identity continuity can be carried by type, color, spatial hierarchy, signature and evidence framing.

### 2.5 Ceremonial
Result: PASS.

R4 can supply major material events without importing Bestiary B0.
Celestial Mass, Membrane/Void, Porous Marrow and controlled Sculptural/Figure Presence are sufficient.

Bestiary entities remain excluded by default.

## 3. Composition <-> Motion

### 3.1 Contemplative
PASS.

Sparse Negative Revelation supports quiet structure.
Repeated Registration is correctly discouraged.

### 3.2 Editorial / Systemic
PASS.

Negative Revelation + Registration map directly to H-B/P4 structure.

### 3.3 Anatomical / Topographic
PASS.

Bounded Dissection mapping can expose sectional/layer relations without adding gore or literal cutting.

### 3.4 Information-Dense
PASS WITH CLARIFICATION.

Motion must not become part of the reading dependency.

**Binding clarification:** both the initial and resolved states of an information-dense transition must remain valid, legible composition states. Motion may reveal or reconcile; it may not temporarily destroy the only comprehensible hierarchy.

### 3.5 Ceremonial
PASS.

The full P5 choreography is allowed but the R3 spectacle ceiling remains controlling.

## 4. Image <-> Motion

### 4.1 Negative Revelation
PASS.

Works naturally with Membrane/Void, Celestial Mass, Topographic/Coastal and active-negative-space treatments.

**Rule:** reveal by mask/withdrawal/exposure, not liquid morphing.

### 4.2 Registration
PASS.

Printed Evidence already provides the plate/layer metaphor.

**Rule:** Registration moves/reconciles layers or fragments. It does not chromatically glitch, melt or synthesize a new image family.

### 4.3 Dissection mapping
PASS.

Geological, marrow, topographic and printed layers provide real sectional targets.

**Rule:** separation must correspond to an actual evidence/matter structure.

### 4.4 Illumination mapping
PASS.

Localized semantic disclosure matches Core and R4 lighting contracts.

**Rule:** no glow language beyond the locked color semantics.

### 4.5 Mirror mapping
PASS WITH CLARIFICATION.

Mirror can conflict with R3's asymmetry-default rule if overgeneralized.

**Binding clarification:** bilateral/mirror motion is a conditional semantic operation only. It is justified by signature/palindrome, anatomy, conceptual equivalence or ceremonial reconciliation—not by visual symmetry preference.

## 5. Five adjudicated tensions

### T1 — D2 expressive mosaic vs. R4 family mixing
Classification: CLARIFICATION.

Potential conflict:
P4/R3 encourage structural variety while R4 defaults to one dominant + one supporting image family.

Adjudication:
- D2 may contain many fragments and heterogeneous structures;
- those fragments should normally derive from no more than two primary image families plus treatment overlays and one localized crimson event;
- “many structures” does not require “many unrelated image families.”

This prevents collage drift while preserving expressive variety.

### T2 — historical annotation logic vs. P2 Minimal / No-Icons
Classification: CLARIFICATION.

Older grammar permitted folio, plate, coordinate and specimen behaviors.

Adjudication:
P2 is later and controlling.
Only content-specific, truthful labels/markers survive.
Fake coordinates, decorative scales, untargeted lines and pseudo-scientific metadata remain prohibited.

### T3 — legacy Illuminated Page vs. anti-pastiche
Classification: CLARIFICATION.

The frozen Master Plan used the label `Illuminated Page`.

Adjudication:
the functional intent survives as controlled page hierarchy, margin/center relation, localized revelation and ritual emphasis.
Literal manuscript recreation, ornamental medievalism and historical cosplay do not survive.

Current operational modes Editorial/Systemic and Ceremonial absorb this function.

### T4 — MIRROR vs. asymmetry default
Classification: CLARIFICATION.

Adjudication:
asymmetry remains default composition behavior.
Mirror/bilateral symmetry is activated only when it carries a real conceptual or signature relation.

### T5 — Sculptural/Figure Presence vs. dark-luxury drift
Classification: CLARIFICATION.

Adjudication:
figure presence requires a declared narrative role and is rejected if a generic statue/bust could be substituted without changing meaning.
