# Naming Workbench

## Current objective
Choose a durable agency name before developing final identity systems.

## Evaluation dimensions
- semantic strength
- pronunciation ES/EN
- memorability
- spelling friction
- distinctiveness
- extensibility beyond AI/marketing/healthcare
- category collisions
- searchability / preliminary ownability signals
- wordmark potential
- narrative potential
