# Naming Workbench

## Current objective
Choose a durable agency name before developing final identity systems.

## Evaluation dimensions
- semantic strength
- pronunciation ES/EN
- memorability
- spelling friction
- distinctiveness
- extensibility beyond AI/marketing/healthcare
- category collisions
- searchability / preliminary ownability signals
- wordmark potential
- narrative potential

## Existing research-only candidates
From Spark exploration (none approved):
- Chirograph
- Horologium
- Macario
- Ossein
- Umbraculum
- Canonicus
- Lucernaria
- Basalt
- Vertebra
- Apocrypha

## Naming exploration outcome — current strong candidates
After multiple divergent rounds, palindrome-focused exploration, phonetic mutation, and preliminary collision screening, the current strongest candidates are:

1. **DIVINIVID** — invented palindrome; strong semantic resonance around divine / vivid / living divinity; preliminary web screening found no obvious direct agency collision.
2. **MAANAAM** — invented palindrome; derived from the Mana/Manam sound family; strong ritual/mantra/symmetry quality; retains some searchability risk because of nearby existing `MAANAM` usage.

### Rejected / downgraded during screening
- REVIVER — conceptually strong but direct branding/creative/technology collisions.
- MANAM / MAANAM — direct/near-direct agency and cultural collisions.
- DEIFIED — direct design/media/AI-service collisions.
- ANIMINA — direct creative-services collisions.

## Next gate
Run a controlled **Brand Test V0** for DIVINIVID and MAANAAM using the same test conditions before any naming freeze.

## Rule
Visual affinity with a candidate is not sufficient for naming approval. Validation follows shortlist creation, and Brand V0 remains provisional until Brand/Business Fit Review.
