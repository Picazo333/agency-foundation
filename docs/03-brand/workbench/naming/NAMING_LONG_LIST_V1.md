# Naming Long List V1 — Historical Salvage

> **Historical artifact.** This list is preserved from the earlier naming branch for traceability. It does not represent the current shortlist. `NAMING_WORKBENCH.md` is authoritative for current naming state.

## Purpose
First curated naming longlist after internal filtering for cliché, obvious generic AI/agency language, poor ES/EN pronunciation, weak extensibility, and obvious direct category collisions discovered in an early quick web screen.

This was **not** trademark clearance, domain clearance, or final availability validation.

## Founder signal: MARROW
`Marrow` was an important phonetic and semantic benchmark because the sound and imagery strongly resonated with inner structure, substance, depth and core matter.

An early web screen found an existing `Marrow` brand identity / strategic design studio, so it was treated as a **reference anchor rather than a clean final candidate** pending any later legal/category assessment.

## Names removed early because of visible direct/near-direct category collisions
Examples: Ductus, Ashlar, Limen, Tessera, Spolia, Siglum, Ramus, Pith, Nidus, Caisson, Archivolt, Silex, Quoin, Parvis, Murex, Brume, Scholium, Narthex, Armarium, Indicia, Intrados, Diopter, Morven.

# Territory 01 — Script / Trace / Inscription

1. **Sigla** — manuscript-adjacent, systematic; visible communication/architecture collision risk.
2. **Notae** — notes, marks, notation and recorded knowledge.
3. **Quire** — folded-sheet/bookmaking term; tactile/historical/system-like.
4. **Colophon** — publishing/end-matter/authorship/production.
5. **Codicil** — addition/amendment to an existing document; legal association risk.

# Territory 02 — Anatomy / Structure / Inner Form

6. **Marrow** — reference anchor; direct category-collision concern.
7. **Ossein** — organic material within bone; structure/anatomical intelligence/inner matter.
8. **Trabecula** — structural lattice/strut within tissue and bone; pronunciation friction.
9. **Plica** — anatomical fold/ridge; short and structural.
10. **Raphe** — seam/line of union in anatomy; ES/EN pronunciation risk.

# Territory 03 — Architecture / Order / Construction

11. **Extrados** — outer surface of arch/vault; structural and uncommon.
12. **Tracery** — Gothic structural ornament; structure + ornament bridge.
13. **Spandrel** — structurally created architectural space; long/intellectual.
14. **Aedicule** — small shrine/niche; sacred/architectural but pronunciation/religious association risk.
15. **Squinch** — architectural square-to-dome transition; transformation metaphor, quirky phonetics.

# Territory 04 — Observation / Instrument / Measure

16. **Ephemeris** — table of celestial positions; observation/prediction/systems/astronomy.
17. **Alidade** — sighting/navigation/surveying device; orientation and precision.
18. **Abscissa** — coordinate/measurement term; structured but technical.
19. **Isogon** — equal-angular-value line; technical/ownable-feeling.
20. **Ecliptic** — apparent solar path; stronger collision likelihood.

# Territory 05 — Archive / Memory / Knowledge

21. **Variorum** — edition with notes/readings from multiple sources; synthesis/accumulated intelligence.
22. **Tabularium** — Roman archive; monumental/institutional.
23. **Florilegium** — selected passages/excerpts; curation/knowledge harvest.
24. **Excerpta** — collected extracts/selections.
25. **Cartulary** — register/collection of charters/records.

# Territory 06 — Liminal / Sacred / Threshold

26. **Votive** — dedicated/offered in fulfillment of a vow; sacred without explicit denomination.
27. **Chancel** — sacred architectural space; explicit church association.
28. **Lustrum** — cycle/period and purification rite; compact/ritual/renewal.
29. **Oriel** — projecting window; light/threshold/observation.
30. **Vespertine** — of the evening; nocturnal without obvious Gothic wording.

# Territory 07 — Matter / Relic / Object

31. **Porphyry** — historical purple-red stone; permanence/materiality.
32. **Ferrule** — strengthening/joining sleeve; connection/reinforcement.
33. **Sinter** — particles bound by heat/pressure; transformation/process.
34. **Intaglio** — incised/engraved image-making process.
35. **Nacre** — mother-of-pearl; layering/iridescence/organic structure.

# Territory 08 — Opaque / Proprietary Phonetic Experiments

36. **Vellor**
37. **Mavren**
38. **Verren**
39. **Serren**
40. **Orren**

These deliberately tested whether the Brand could carry meaning rather than inherit it.

## Historical signal leaders at that moment
Not a ranking: Ossein, Variorum, Alidade, Ferrule, Lustrum, Tracery, Votive, Quire. Marrow remained a preference benchmark.

## Why this artifact matters now
The later process moved substantially beyond this list into sacred phonetics, palindrome exploration and coined forms, culminating in the current working selection `DIVINIVID`. This artifact is retained only to preserve the path and avoid repeating discarded territory work.
