# Current Visual Direction

## Core tension
> **The coexistence of sacred beauty and horror.**

More specifically: colorful medieval illumination + structural darkness + classical medical/anatomical illustration + symbolic grotesque + contemporary digital precision.

## Strong preferences
- illuminated manuscripts / codices
- angels, bestiaries, hybrid creatures, sacred/grotesque imagery
- chiaroscuro and large fields of darkness
- classical medical/anatomical engraving
- expressionist distortion / Caligari-like spatial tension
- black-and-white cinema / nocturnal sacred atmosphere
- ivory/parchment, black/charcoal, ultramarine, crimson/vermilion, aged gold
- editorial typography and information-rich annotation systems

## Anti-profile
- purple/cyan AI gradients
- neon tech
- glassmorphism
- generic SaaS bento identity
- pseudo-luxury black/gold
- Pinterest dark academia
- generic gothic/occult shortcuts
- trendy brutalist agency templates
- random grunge
- fantasy-medieval cosplay
- visual chaos without hierarchy

## Current high-signal identity territories
1. Illuminated Chirograph
2. Sacred Anatomy
3. Angelic Grotesque
4. Cathedral of Systems
5. Anatomical Bestiary (wild card)

## Important correction
The project has moved beyond open moodboarding. Future explorations should demonstrate **identity systems**: name/wordmark, typography, palette, imagery/illustration, graphic devices, grid/composition, iconography, motion, web/UI behavior, social/deck applications.
