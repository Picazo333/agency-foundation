## Stage F — Brand Vertical Slice Prototype

After Final Expression Lock, build one **prototype-level vertical slice** whose purpose is to prove the finished Brand as a coherent experience.

This is **not** the production website and is not the Agency MVS.

### Prototype definition

One coherent responsive slice, preferably a single page/flow, demonstrating at minimum:

- DIVINIVID signature/wordmark;
- plain register + expressive/full register relationship;
- desktop + mobile translation;
- navigation/header behavior;
- primary hero/orientation;
- visible method/evidence section;
- service/system explanation;
- one dense data/report/evidence module;
- one controlled image/matter event;
- CTA/conversion affordance as a prototype only;
- representative P5 motion behavior;
- reduced-motion equivalent;
- ivory/light and Living Darkness behavior;
- accessibility-aware hierarchy.

The prototype may use clearly labelled provisional copy where market language is not validated.

It must not fake:
- testimonials;
- clients;
- outcome metrics;
- validated ICP claims;
- validated price;
- final production IA.

### Prototype fidelity

High enough to test:
- identity coherence;
- responsive hierarchy;
- transition between plain/full registers;
- long-form/data legibility;
- motion restraint;
- perceived trust/rigor;
- implementation plausibility.

Not high enough to trigger:
- full component library;
- complete site architecture;
- backend;
- CRM;
- analytics;
- production code;
- final marketing content.
