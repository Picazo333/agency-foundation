# Handoff Protocol

Every substantial handoff should contain:
1. Objective completed.
2. Inputs used.
3. Outputs produced.
4. Decisions proposed versus facts observed.
5. Files changed.
6. What was intentionally not changed.
7. Risks/gaps.
8. Dependencies created.
9. Recommended next action.
10. Definition-of-Done evidence.

Handoffs live under `docs/09-handoffs/<tool>/` and should link the relevant PR/commit when applicable.
