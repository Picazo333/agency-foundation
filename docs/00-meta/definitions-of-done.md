# Definitions of Done

## Research task
- Source index present.
- Facts separated from inference/hypothesis.
- Decision implication stated.
- Gaps/limitations explicit.

## Brand exploration
- Alternatives are materially distinct.
- Naming/visual rationale documented.
- Anti-patterns respected.
- System demonstrated beyond a collage: typography, color, imagery, composition, UI/web behavior.

## Strategic plan
- Assumptions explicit.
- Evidence dependencies explicit.
- Kill criteria and validation plan included.
- Does not silently freeze unvalidated claims.

## Code/technical work
- Scope respected.
- Tests/build/checks pass where relevant.
- Security/accessibility/performance implications noted.
- Screenshots/artifacts supplied for visible changes.
- Documentation updated.

## Asset production
- Conforms to Brand V1.
- Provenance/license recorded.
- Format/dimensions/variants documented.
- Responsive/usage behavior specified.
