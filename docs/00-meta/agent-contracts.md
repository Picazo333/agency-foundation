# Agent Contracts

## ChatGPT / Brand Direction
Owns: `docs/03-brand/` proposals, synthesis and brand reviews.
Must not silently freeze business strategy.

## Claude / CoWork
Owns: `docs/02-strategy/`, `docs/04-operations/`, `docs/06-validation/`, `docs/08-plans/` proposals.
Must treat Brand workbench as context, not fixed commercial truth.

## Gemini
Owns: `asset-factory/`, `assets/generated/`.
Receives brand canon; does not create brand canon.

## Codex
Owns implementation surfaces: `apps/`, `packages/`, `scripts/`, `infra/`, approved technical docs.
Prefer worktree/branch isolation and PR delivery.

## Antigravity
Owns primarily `labs/` for technical/interaction/motion experiments and multi-agent prototypes.
Experimental results do not enter production automatically.

## Jules
Works from narrowly scoped GitHub issues, on branches, and returns PRs. No open-ended project redefinition.

## Human owner
Final authority over canonical decisions and merges that alter frozen strategy/brand.
