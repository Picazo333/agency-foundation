# Source of Truth

## Authority classes
1. **FROZEN canon** — approved decisions/specifications.
2. **APPROVED canon** — accepted but still reopenable with explicit rationale.
3. **REVIEW** — candidate for canon.
4. **DRAFT / workbench** — exploration, not truth.
5. **RESEARCH-ONLY** — evidence or external analysis; may contain errors or hypotheses.
6. **REJECTED / DEPRECATED / SUPERSEDED** — retained only for history.

## Critical rule
Being merged into the repository does not automatically mean an artifact is a strategic truth. Authority is determined by location + status metadata + ADR.

## Research rule
Research may inform decisions but cannot silently become a decision. Unsupported precision must remain hypothesis/unknown.
