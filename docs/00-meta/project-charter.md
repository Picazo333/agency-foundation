# Project Charter

## Mission
Create a differentiated, commercially viable agency with a coherent brand, evidence-based strategy, repeatable delivery, high-quality web/system implementation and an operating model that can evolve without losing project memory.

## Current program boundary
The agency's final commercial form is not yet frozen. Brand exploration can proceed to V0, but the final Brand V1 must pass business-fit review.

## Definition of program success
A separate implementation/operations team can execute the agency without reopening fundamental decisions, while open hypotheses remain explicitly identified for field validation.
