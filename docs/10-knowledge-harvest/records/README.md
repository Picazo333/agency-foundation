# Harvest Records

Store one record per meaningful event using `../templates/HARVEST_RECORD_TEMPLATE.md`.

Recommended filename:

`HARVEST-YYYYMMDD-short-slug.md`

Rules:

- one meaningful event normally creates one record;
- multiple downstream routes may be declared in one record;
- do not place secrets or unredacted restricted client data here;
- records are reusable knowledge candidates, not strategic canon;
- use status metadata to distinguish candidate/reviewed/approved/deprecated records;
- link to source PR/ADR/issue/artifact instead of duplicating large bodies of source material.
