# ADR-0003 — Parallel workstreams

Status: APPROVED
Date: 2026-09-15

## Decision
Run Brand, Claude Master Plan, Gemini Asset Factory architecture and Technical Foundation concurrently where dependencies permit.

## Why
The workstreams have substantial independent work and available specialized tools.

## Consequences
Shorter critical path, but stronger handoff/governance requirements.

## Reopen if
Parallelism creates more coordination cost than value.
