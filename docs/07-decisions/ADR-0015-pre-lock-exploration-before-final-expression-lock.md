# ADR-0015 — Insert a Pre-Lock Exploration Program before final expression lock

Status: APPROVED
Date: 2026-09-22

## Context
ADR-0014 replaced mandatory mass moodboard rendering with targeted visual synthesis and established:
- the Core Lock;
- B1 (Route 3+4) as the principal production base;
- B0 (Route 3+5) as the bestiary branch;
- an M1/M2 path toward MAIN_SYSTEM_B2.

The subsequent M1 work produced a stronger breakthrough:
- M1-A remains useful morphology evidence;
- M1-B / Topografía Orgánica is human-approved as the current **pre-lock working anchor**.

At this point the largest remaining uncertainty is no longer whether the visual universe exists. It is whether the universe can behave as a complete identity system across typography, signs, hero, motion, digital interface, intensity levels and real applications.

Moving directly to an isolated brutalist mutation would answer less than testing those system behaviors directly.

## Decision
Insert `DIVINIVID_PRE_LOCK_EXPLORATION_V1` before final expression lock.

The program will:
1. preserve Core and B1;
2. use M1-B as a working anchor, not final canon;
3. test seven system layers with bounded candidates;
4. synthesize only human-approved module outputs;
5. perform an independent red team before final promotion;
6. require an explicit human gate for `DIVINIVID_FINAL_EXPRESSION_LOCK_V1`.

## Program order
`Typography -> Iconography -> Hero -> Density -> Motion -> Digital Behavior -> Application Stress -> Final Synthesis -> Red Team -> Human Final Gate`.

## Change to ADR-0014 sequence
ADR-0014's immediate M2-Soft/M2-Hard brutalist comparison is superseded as the next gate.

Brutalist discipline is now tested where it materially belongs:
- typography;
- hierarchy;
- hero;
- density;
- digital behavior;
- application stress.

A later explicit brutalist study remains possible only if these modules show unresolved need.

## Working-anchor status
M1-B is:
- human-approved for pre-lock exploration;
- not yet the final expression lock;
- not a replacement for Core/B1 authority;
- prohibited from silently promoting its incidental typography/iconography/details.

## Why
This path:
- extracts more evidence from the visual breakthrough before industrialization;
- reduces risk of locking accidental typography/iconography;
- tests commercial and digital viability before Figma system build;
- converts aesthetics into behavior;
- avoids a redundant standalone brutalism phase unless evidence justifies it.

## Trade-offs
- adds a bounded exploration stage before Figma production;
- requires several small comparative artifacts;
- delays final expression lock slightly in exchange for higher confidence.

## Reopen if
- pre-lock testing reveals a foundational failure in B1;
- no typography/sign/hero system can preserve the working anchor;
- digital/application stress shows the identity is not operationally elastic;
- the human owner explicitly changes scope.
