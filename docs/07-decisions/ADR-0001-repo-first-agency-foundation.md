# ADR-0001 — Repo-first Agency Foundation

Status: APPROVED
Date: 2026-09-15

## Decision
Use this repository as the persistent source of truth for agency research, decisions, plans, brand, operations, assets and implementation.

## Why
The project now has multiple AI workers and enough parallelism that coordination/versioning is a primary risk.

## Consequences
Major outputs should be versioned and reviewed; chat history alone is not authoritative.

## Reopen if
A substantially better project-state system replaces Git-based coordination.
