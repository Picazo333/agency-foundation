# ADR-0013 — Move DIVINIVID from visual discovery into controlled universe expansion before Asset Factory production

Status: APPROVED
Date: 2026-09-20

## Context
The 2026-09-16 visual plan intentionally blocked generated identity production until the source-only Reference Atlas passed. Subsequent human-guided work continued through extensive visual iteration and has now produced a coherent, repeatedly approved DIVINIVID visual baseline plus substantial application, Bestiary, structural, motion and physical-world exploration.

The current risk has changed. The primary risk is no longer premature aesthetic selection; it is losing provenance, creating redundant exploration, or entering industrial asset production without complete coverage and executable visual specifications.

## Decision
Adopt the sequencing defined by `docs/08-plans/master/DIVINIVID_VISUAL_UNIVERSE_META_PLAN_V2.md`:

`Archive/Inventory -> Canon/Lineage -> 100-board Specification -> 100-board Execution -> Coverage Audit/Gap Loop -> Visual Spec/Matrix/Ontology -> Golden-set Pilot -> Asset Factory -> Brandbook -> Final QA/Release`.

Before resuming execution, reconcile the plan through Noema and Skill Foundry as documented in the meta-plan.

The previous Reference Atlas/Tension Grammar/route-production sequence remains historical evidence and research context but is superseded as the active execution gate.

## Alternatives considered
- return to the 2026-09-16 Phase 3 gate and discard later human-approved exploration;
- begin mass asset generation immediately;
- continue open-ended moodboarding without a coverage model.

## Why
The new sequence preserves the value of the already-created universe while adding the missing controls: inventory, negative evidence, coverage, production specification, factory pilot and final governance.

## Consequences
### Positive
- chat history stops being required project memory;
- failures become reusable anti-pattern evidence;
- moodboards gain explicit coverage purpose;
- Gemini can later operate as a factory rather than a creative rediscovery engine;
- Asset Factory receives a tested Brand Pack rather than aesthetic prose.

### Trade-offs
- additional governance work is required before new generation resumes;
- exact file inventory and canon promotion become mandatory;
- some visually strong work may remain support evidence rather than canon.

## Evidence / assumptions
Human approvals and corrections across the current DIVINIVID visual-universe program; existing Asset Factory architecture; Noema reference audit of Agency Foundation; current Skill Foundry Brand capability suite.

## Reopen if
- archive evidence contradicts the assumed visual baseline;
- coverage audit finds foundational rather than local gaps;
- the golden-set pilot proves the production contracts are not executable.
