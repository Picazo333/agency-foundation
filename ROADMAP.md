# Roadmap

## Wave 0 — Foundation
- Repository baseline
- Source-of-truth rules
- Decision/ADR system
- Workstream specs
- Handoff templates

## Wave 1 — Parallel discovery/planning
- Brand: naming + identity V0
- Strategy: Agency Master Plan
- Gemini: Asset Factory architecture
- Technical: neutral foundations and labs

## Gate 1 — Brand/Business Fit
Evaluate whether Brand V0 fits the emerging commercial model.

## Wave 2 — Strategic convergence
Freeze agency thesis, category, ICP hypothesis, positioning, offer, pricing model, proof strategy, recurring model, sales motion and delivery model; mark field-validation dependencies explicitly.

## Wave 3 — Full Brand System V1
New clean brand-system workstream using Brand V0 + business strategy.

## Wave 4 — Asset Factory activation
Generate approved, traceable SVG/illustration/pattern/social/deck/web asset libraries.

## Wave 5 — Implementation
Parallel Aesthetic / Functional / System spines.

## Wave 6 — Market validation
Validate WTP, buyer language, offer clarity, pricing, objections, access and proof.

## Wave 7 — Integration + launch
Production web, sales system, CRM, automations, onboarding, proof capture, analytics.

## Wave 8 — Measure + iterate
Evidence-driven iteration; reopen frozen decisions only through explicit ADR.
