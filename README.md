## Operating principles

**Research is not canon. Workbench is not canon. Only reviewed and approved artifacts become canonical.**

**Capability contracts outlive individual tools.** A workstream may change executor when doing so reduces coordination/setup cost without weakening scope, validation or Definition of Done.

All substantial agent work should arrive as an isolated branch/task + PR with a defined scope and Definition of Done.
